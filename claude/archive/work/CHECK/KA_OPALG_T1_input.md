## 2. C3-Q1: decidibilità nel modello olonomo analitico
**[OP-ALG-D1] Modello M3-hol.** Ingresso: (i) Ω ⊂ ℝ² aperto connesso, p₀ = (t₀,x₀) ∈ Ω ∩ K²; (ii) u reale-analitica su Ω (a valori complessi); (iii) generatori H_1,…,H_s ∈ A_2(K) di un ideale sinistro I con I ⊆ Ann_{A_2}(u) (cioè H_lu = 0 su Ω) e A_2(K)/I olonomo; (iv) oracolo dei getti: per ogni α, ∂^αu(p₀) ∈ 𝕂; (v) P ∈ K[τ,ξ] non costante con la fattorizzazione P = c∏P_i^{e_i} in irriducibili su ℂ, a due a due non associati, P_i ∈ K[τ,ξ]. (AC).
*Commento.* È il modello "u olonoma data come formula": per le espressioni chiuse olonome (somme, prodotti, derivate, composizioni algebriche di funzioni olonome) un ideale olonomo I si costruisce con le proprietà di chiusura (Zeilberger 1990, Chyzak 2000: CON-FONTE generico, non verificato sul testo); i getti in p₀ sono numeri del campo generato dai dati (p. es. per dati esponenziali con esponenti algebrici ℚ-linearmente indipendenti, 𝕂 = ℚ̄(e^{α_1},…) è puramente trascendente su ℚ̄ per Lindemann–Weierstrass, quindi computabile). Non si richiede che p₀ sia un punto regolare di I, né che P sia monico.

### [OP-ALG-L1] Eliminanti di Bernstein — PROVA SCRITTA (argomento classico di conteggio)
*Ipotesi.* N = A_2(K)/I olonomo, M ∈ A_2(K), m := M·1̄ ∈ N; S ∈ {S_t := K[t,x]⟨∂_t⟩, S_x := K[t,x]⟨∂_x⟩}.
*Tesi.* (a) Esiste L ∈ S∖{0} con L·m = 0, cioè LM ∈ I. (b) Un tale L è calcolabile dai generatori di I (solo algebra lineare su K). (c) Se M = M(∂) ∈ K[∂] (o M qualsiasi) allora L annulla la funzione Mu su Ω.
*Prova.* (a) Sia d il grado di Bernstein di M. Per S = S_t, S_k := S ∩ F_kA_2 ha base {t^ax^b∂_t^c : a+b+c ≤ k}, dimensione binom(k+3,3). La mappa lineare S_k → N, L ↦ L·m, ha immagine in F_{k+d}N (F_kA_2·F_dA_2 ⊆ F_{k+d}A_2), di dimensione ≤ C(k+d+1)² per una costante C (olonomia). Poiché binom(k+3,3) ~ k³/6, per k grande il nucleo è non nullo. Lo stesso per S_x. (b) Per h = 0,1,2,…: incognite L ∈ S_h e C_1,…,C_s ∈ F_hA_2; l'equazione LM − Σ_lC_lH_l = 0, scritta in forma normale, è un sistema lineare omogeneo a coefficienti in K; si calcola una base del suo spazio delle soluzioni e si guarda se la proiezione sulla componente L è non nulla. Per (a) esistono L ≠ 0 e C_l con LM = ΣC_lH_l (I è generato dagli H_l); per h ≥ max dei gradi la ricerca lo trova: termina, ed è corretta perché LM ∈ I. (c) LM ∈ I ⊆ Ann_{A_2}(u), quindi L(Mu) = (LM)u = 0. ∎

### [OP-ALG-L2] Test di zero con polinomio indiciale a parametro — PROVA SCRITTA
*Ipotesi.* v analitica in un intorno di p₀ = (t₀,x₀); L = Σ_{j≤r}b_j(t,x)∂_t^j ∈ K[t,x]⟨∂_t⟩∖{0} con Lv = 0 vicino a p₀. Scriviamo b_j(t,x) = Σ_iβ_{ij}(x)(t−t₀)^i (somma finita, β_{ij} ∈ K[x]); δ := min{i − j : β_{ij} ≢ 0}; ι(n;x) := Σ_{i−j=δ}β_{ij}(x)n^{\underline j} ∈ K[x][n]; Z := {n ∈ ℕ : ι(n;·) ≡ 0}; K₀ := max Z (K₀ := −1 se Z = ∅).
*Tesi.* (i) ι ≠ 0, Z è finito e calcolabile (AC). (ii) v ≡ 0 vicino a p₀ ⟺ c_n ≡ 0 vicino a x₀ per ogni n ≤ K₀, dove c_n(x) := ∂_t^nv(t₀,x)/n!.
*Prova.* (i) Per definizione di δ esiste una coppia (i,j) con i − j = δ e β_{ij} ≢ 0; i fattoriali decrescenti n^{\underline j} con j distinti hanno gradi distinti in n, quindi sono K[x]-linearmente indipendenti e ι ≠ 0. Scritto ι = Σ_lx^lι_l(n) con ι_l ∈ K[n] non tutti nulli, Z ⊆ {radici di un ι_l ≠ 0}: finito; le radici intere ≥ 0 del gcd degli ι_l si calcolano con (AC). (δ esiste: i ≥ 0, j ≤ r, quindi i − j ≥ −r.)
(ii) (⇐) Su un polidisco complesso centrato in p₀ v è olomorfa e v = Σ_nc_n(x)(t−t₀)^n con c_n olomorfe in un disco attorno a x₀. Supponiamo v ≢ 0 vicino a p₀: esiste n₀ := min{n : c_n ≢ 0}. Poiché (t−t₀)^i∂_t^j(t−t₀)^n = n^{\underline j}(t−t₀)^{n+i−j}, si ha Lv = Σ_nΣ_{i,j}β_{ij}(x)n^{\underline j}c_n(x)(t−t₀)^{n+i−j} (serie assolutamente convergente, derivabile termine a termine). Il coefficiente di (t−t₀)^{n₀+δ} riceve contributi solo da n = n₀ e i − j = δ (per n > n₀ gli esponenti sono ≥ n + δ > n₀ + δ; per n < n₀, c_n = 0): vale ι(n₀;x)c_{n₀}(x) = 0 vicino a x₀. c_{n₀} è olomorfa e non identicamente nulla, quindi non nulla su un aperto denso del disco; il polinomio ι(n₀;·) si annulla su un aperto, quindi ι(n₀;·) ≡ 0: n₀ ∈ Z, n₀ ≤ K₀. Se dunque c_n ≡ 0 per ogni n ≤ K₀, nessun n₀ può esistere e v ≡ 0. (⇒) ovvio. ∎
*Controlli.* SymPy Q1-E3a–d: per il nucleo del calore G, L = 4t²∂_t + 2t − x², in p₀ = (1,0): ι = 4n, K₀ = 0 (punto regolare); L = t∂_t − 3 in t₀ = 0: K₀ = 3 (punto singolare, v = t³x); L = (x+1)(t∂_t − 2): ι = (x+1)(n−2), K₀ = 2.

### [OP-ALG-P1] Test di zero decidibile in M3-hol — PROVA SCRITTA
*Tesi.* Per ogni L_* ∈ A_2(K), "L_*u = 0 su Ω" è decidibile.
*Prova (algoritmo).* Sia v := L_*u, analitica su Ω (connesso): v ≡ 0 su Ω ⟺ v ≡ 0 vicino a p₀. *Getti di v:* ∂^αv(p₀) è una combinazione finita, a coefficienti in K (derivate dei coefficienti polinomiali di L_* in p₀ ∈ K²), di getti di u (Leibniz): calcolabili in 𝕂. *Passo 1.* OP-ALG-L1 con M = L_*, S = S_t: L ∈ S_t∖0 con Lv = 0; OP-ALG-L2 dà K₀. *Passo 2.* Per ogni n ≤ K₀: OP-ALG-L1 con M = ∂_t^nL_*, S = S_x: L′_n con L′_n(∂_t^nv) = 0; OP-ALG-L3 dà Λ_n ∈ K[x]⟨∂_x⟩∖0 con Λ_n c_n = 0 vicino a x₀ (c_n = ∂_t^nv(t₀,·)/n!). *Passo 3.* P4-L4 (test di zero indiciale in una variabile, DIMOSTRATO, vale anche in punti singolari): c_n ≡ 0 vicino a x₀ ⟺ c_n^{(k)}(x₀) = 0 per k ≤ K₀(Λ_n, x₀), cioè ∂_x^k∂_t^nv(p₀) = 0: un numero finito di getti, test di uguaglianza in 𝕂. *Passo 4.* Per OP-ALG-L2(ii), v ≡ 0 vicino a p₀ ⟺ tutti i test del Passo 3 danno "nullo". ### [OP-ALG-L4] Confinamento della parte EP — PROVA SCRITTA (estende P4-L3 a due variabili)
*Ipotesi.* w analitica su Ω connesso; L = Σ_{i,j}β_{ij}(x)t^i∂_t^j ∈ K[t,x]⟨∂_t⟩∖0 e L′ = Σ_{i,j}β′_{ij}(t)x^i∂_x^j ∈ K[t,x]⟨∂_x⟩∖0 con Lw = L′w = 0 su Ω.
*Costruzione (t).* D := max{i : ∃j β_{ij} ≢ 0}; M_D(x;τ) := Σ_jβ_{Dj}(x)τ^j ∈ K[x][τ]∖0; T_t := {τ ∈ ℂ : M_D(·;τ) ≡ 0} (= radici del gcd dei coefficienti in x di M_D: finito, ⊂ K, calcolabile). Per τ ∈ T_t, L_τ := Σβ_{ij}(x)t^i(∂_t+τ)^j = Σ_{i,l}γ_{il}(x)t^i∂_t^l ≠ 0, δ_τ := max{i − l : γ_{il} ≢ 0}, ι_τ(n;x) := Σ_{i−l=δ_τ}γ_{il}(x)n^{\underline l} ∈ K[x][n]∖0, N_t(τ) := max{n ∈ ℕ : ι_τ(n;·) ≡ 0} (−1 se vuoto). Analogamente (scambiando t ↔ x, τ ↔ ξ, usando L′) T_x e N_x.
*Tesi.* (i) Se w ∈ EP(Ω), allora w ∈ E(w) := span{t^ax^be^{τt+ξx} : τ ∈ T_t, a ≤ N_t(τ), ξ ∈ T_x, b ≤ N_x(ξ)}. (ii) E(w) è di dimensione finita, stabile per ∂_t e ∂_x, ed è annullato da a*(∂_t) e b*(∂_x), con a*(τ) := ∏_{τ′∈T_t, N_t(τ′)≥0}(τ−τ′)^{N_t(τ′)+1} e b*(ξ) := ∏_{ξ′∈T_x, N_x(ξ′)≥0}(ξ−ξ′)^{N_x(ξ′)+1} (prodotto vuoto = 1).
*Prova.* (i) Sia w = Σ_kq_ke^{⟨z_k,·⟩}, z_k = (τ_k,ξ_k) distinti, q_k ∈ ℂ[t,x]∖0 (rappresentazione unica, C3-L3(b)). Poiché e^{−⟨z,y⟩}∂_te^{⟨z,y⟩} = ∂_t + τ e i coefficienti di L non dipendono da ∂_x, Lw = Σ_ke^{⟨z_k,·⟩}L_{τ_k}q_k con L_{τ_k}q_k ∈ ℂ[t,x]; per C3-L3(b) ogni L_{τ_k}q_k = 0. Fissato k, scriviamo q := q_k = Σ_{a≤ν}t^ar_a(x), r_ν ≢ 0, τ := τ_k. *Esponente.* In L_τq = Σβ_{ij}(x)t^iΣ_{l≤j}binom(j,l)τ^{j−l}∂_t^lq il monomio t^{D+ν} riceve solo il contributo di i = D, l = 0, a = ν (gli altri termini hanno grado in t ≤ i + a − l < D + ν): coefficiente M_D(x;τ)r_ν(x) = 0, dunque M_D(·;τ) ≡ 0 e τ ∈ T_t. M_D ≢ 0 perché qualche β_{Dj} ≢ 0 e le potenze τ^j sono indipendenti: T_t è finito. *Grado.* L_τ = Σγ_{il}t^i∂_t^l, t^i∂_t^lt^a = a^{\underline l}t^{a+i−l}; ogni termine ha i − l ≤ δ_τ; il monomio t^{ν+δ_τ} riceve solo i contributi con a = ν e i − l = δ_τ: coefficiente ι_τ(ν;x)r_ν(x) = 0, dunque ι_τ(ν;·) ≡ 0 e ν ≤ N_t(τ). ι_τ ≠ 0 come in OP-ALG-L2(i). Lo stesso con L′ dà ξ_k ∈ T_x e deg_xq_k ≤ N_x(ξ_k). Quindi ogni addendo sta in E(w). (ii) ∂_t(t^ax^be^{⟨z,y⟩}) = (at^{a−1} + τt^a)x^be^{⟨z,y⟩}: i limiti di grado si conservano; dimensione ≤ (Σ_τ(N_t(τ)+1))(Σ_ξ(N_x(ξ)+1)). (∂_t − τ)^{N+1}(t^ae^{τt}) = 0 per a ≤ N, e (∂_t − τ′)^c è invertibile sui polinomi per τ′ ≠ τ: a*(∂_t) annulla E(w); lo stesso per b*. ∎
