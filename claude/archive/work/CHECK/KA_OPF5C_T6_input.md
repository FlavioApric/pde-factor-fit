## [OPF5C-L9] Decadimento super-polinomiale ⇒ varietà fortemente stabile
*Enunciato.* Sia z′ = Az + g(z) su [x₁, ∞), g di classe C¹ vicino a 0 con g(0) = 0, Dg(0) = 0. Siano E_s ⊕ E_{cu} la decomposizione spettrale di A (Re λ < 0 / Re λ ≥ 0), s := dim E_s, γ := min{−Re λ : Re λ < 0}. (i) Se |z(x)| = O(x^{−n}) per ogni n, allora z(x) = O(e^{−γ′x}) per ogni γ′ < γ e z(x) ∈ W^{ss}_loc per x grande (W^{ss}_loc varietà C¹ di dimensione s tangente a E_s, positivamente invariante; z ≡ 0 definitivamente se s = 0). (ii) Se z(x) = O(e^{−βx}) con β > max{|Re λ|}, allora z ≡ 0 definitivamente.
*Prova.* (i) Costanti: |e^{Ax}P_s| ≤ Ce^{−γ″x} (x ≥ 0, γ′ < γ″ < γ), |e^{Ax}P_{cu}| ≤ C(1+|x|)^m (x ≤ 0), m := dim. Poiché |e^{A(x−y)}P_{cu}z(y)| ≤ C(1+y−x)^m|z(y)| → 0 per y → ∞, la variazione delle costanti dà P_{cu}z(x) = −∫_x^∞ e^{A(x−σ)}P_{cu}g(z(σ))dσ e P_sz(x) = e^{A(x−x₁)}ξ + ∫_{x₁}^x e^{A(x−σ)}P_sg(z(σ))dσ, ξ := P_sz(x₁): z è punto fisso dell'operatore di Lyapunov–Perron T_ξ. Su X_n := {w : ‖w‖_n := sup_{x≥x₁}(1+x−x₁)^n|w(x)| < ∞}, n > m+1: ∫_x^∞(1+σ−x)^m(1+σ−x₁)^{−2n}dσ ≤ (1+x−x₁)^{−n}∫_0^∞(1+τ)^{m−n}dτ e ∫_{x₁}^x e^{−γ″(x−σ)}(1+σ−x₁)^{−2n}dσ ≤ C(1+x−x₁)^{−n} (usando (1+x−x₁)^n ≤ (1+σ−x₁)^n(1+x−σ)^n); con |g(w) − g(w′)| ≤ Cρ|w − w′| sulla palla di raggio ρ, T_ξ è una contrazione della palla B_ρ ⊂ X_n se |ξ| ≤ ρ/(2C) e ρ piccolo. La stessa costruzione nello spazio pesato Y := {sup e^{γ′(x−x₁)}|w| < ∞} dà il punto fisso esponenzialmente decrescente w*_ξ (costruzione standard della varietà stabile forte), e Y ↪ X_n con ‖w*_ξ‖_n ≤ C_n‖w*_ξ‖_Y ≤ C′|ξ|. Scegliendo x₁ grande, ‖z‖_{n,x₁} ≤ sup_{x≥x₁}(1+x)^n|z(x)| → 0 (perché z = O(x^{−n−1})) e |ξ| → 0: z e w*_ξ sono punti fissi nella stessa palla di X_n, quindi coincidono. (ii) Come sopra con E_{cu} = ℝ^m: z(x) = −∫_x^∞e^{A(x−σ)}g(z(σ))dσ; con β′ := max|Re λ| + ε < β, ‖z‖_β := sup_{x≥x₁}e^{βx}|z(x)| soddisfa ‖z‖_β ≤ C(2β − β′)^{−1}e^{−βx₁}‖z‖_β², quindi ‖z‖_β = 0 per x₁ grande (‖z‖_β resta limitato). ∎

## [OPF5C-T6] Relazioni con origine non singolare — ENUNCIATO DA ATTACCARE
*Enunciato.* Sia u come nel quadro. Sia p un germe reale-analitico in 0 ∈ ℝ^{K+1} (per esempio un polinomio; p ∈ J_u a coefficienti complessi si riduce a parte reale o immaginaria), con p(0) = 0 e **α := ∂p/∂y_K(0) ≠ 0**, tale che per ogni t esiste R(t) con p(u, …, u^{(K)})(t, x) = 0 per |x| ≥ R(t). Sia ℓ(z) := Σ_{j≤K}(∂p/∂y_j)(0)z^j e s, n_u il numero di radici (con molteplicità) con Re < 0, Re > 0. Allora:
(a) per ogni t, u(t, x) = O(e^{−γ′x}) per x → +∞ per ogni γ′ < min{−Re z : ℓ(z) = 0, Re z < 0}, e analogamente per x → −∞; se s = 0 oppure n_u = 0, u ≡ 0.
(b) Se per qualche t₀ u(t₀, x) = O(e^{−β|x|}) per x → +∞ (o −∞) con β > max{|Re z| : ℓ(z) = 0}, allora u ≡ 0.
(c) Se min(s, n_u) ≤ 1 — in particolare se K ≤ 3 — allora u ≡ 0 oppure u è un 1-solitone u = (c/2)sech²(√c(x − ct − x₀)/2).
*Prova.* *Forma normale.* Per la funzione implicita analitica, vicino a 0 lo zero di p è il grafico y_K = φ(y_0..y_{K−1}), φ analitica, φ(0) = 0. Fissato t, per |x| grande il getto (u..u^{(K)}) è vicino a 0 (Schwartz) e sta sul grafico: z := (u, …, u^{(K−1)}) risolve z′ = Az + g(z), con A matrice compagna di ℓ/α e g = O(|z|²). Le componenti di z decadono più di ogni potenza.
(a) e (b): L9 a x → +∞ (e con x ↦ −x a −∞: la matrice diventa −A); se z ≡ 0 su una semiretta, u(t,·) ≡ 0 per analiticità e u ≡ 0 per conservazione di ‖u(t)‖_{L²}.
(c) Supponiamo s ≤ 1 (il caso n_u ≤ 1 è simmetrico) e u ≢ 0 (quindi ‖u(t)‖_{L²} = cost > 0 e s = 1 per (a)). W^{ss}_loc è una curva C¹ per 0, grafico su E_s ≅ ℝ, positivamente invariante; il punto con coordinata ξ = 0 è 0. Un'orbita con ξ(x₁) = ξ₀ > 0 non raggiunge 0 in tempo finito (unicità), quindi ξ(x) ∈ (0, ξ₀] e per continuità percorre tutto (0, ξ₀]: W^{ss}_loc∖{0} è unione di **due** archi d'orbita B_±. Per L9(i), per ogni t la coda a +∞ del getto di u(t,·) sta su B_+ o su B_−. Fisso q_± ∈ B_± e, se esiste t_± con coda su B_±, pongo H_± := u(t_±, · + x_±) con getto q_± in 0. Se u(t,·) ha coda su B_+, esiste x₂ con getto q_+ in x₂; u(t, · + x₂) e H_+ risolvono la stessa ODE analitica con lo stesso dato in 0, quindi coincidono su [0, ∞), e per analiticità su ℝ. Quindi ℝ = T_+ ∪ T_−, T_± := {t : u(t,·) ∈ {H_±(· − c) : c ∈ ℝ}}. T_± è chiuso: se u(t_n) = H_±(· − c_n) → u(t) in L², (c_n) è limitata (altrimenti u(t_n) ⇀ 0 debolmente, contro ‖u(t)‖ > 0), e un punto limite c dà u(t) = H_±(· − c). ℝ connesso ⇒ T_+ ∩ T_− ≠ ∅ oppure uno dei due è vuoto: in ogni caso esiste un unico profilo H con u(t, x) = H(x − c(t)) per ogni t. H ∈ 𝒮∖0 non è periodica, quindi c(t) è unica e continua (stesso argomento di compattezza). Scelto x₀ con H′(x₀ − c(t₀)) ≠ 0, c(t) = x₀ − H_loc^{−1}(u(t, x₀)) è liscia vicino a t₀. Da KdV: c′(t)H′ = 6HH′ + H‴, quindi c′ è costante (H′ ≢ 0), u è un'onda viaggiante di Schwartz e H′² = cH² − 2H³: H = (c/2)sech²(√c(ξ − ξ₀)/2), c > 0. ∎
*Corollario.* Se u non è 0 né un 1-solitone: (i) J_u non contiene relazioni d'ordine ≤ 3 con origine non singolare; (ii) ogni relazione di J_u con origine non singolare ha ordine ≥ 4 e ≥ 2 radici di ℓ in ciascun semipiano; (iii) se u(t₀,·) decade più che esponenzialmente a un estremo, J_u non contiene alcuna relazione con origine non singolare. Coerenza: l'N-solitone soddisfa la relazione stazionaria di Novikov (origine non singolare, ℓ(z) ∝ Π(z² − k_i²), s = n_u = N).
