# KA input — OPF5B-T2 / P3 / C4 (enunciato, ipotesi, prova; solo questo)
Contesto minimo: OP-ALG-T4 (dato per vero): per P monico in ∂_t di grado m, u con Pu=0: Ann_𝔇(u)=𝔇P ⟺ (b) i getti ∂_t^j u, j<m, sono 𝔄-liberi ⟺ (d) nessun Q ∈ 𝔇∖𝔇P con Qu ∈ 𝒯 (𝒯 = elementi di 𝔄-torsione di ℱ). OP-ALG-L5: (a) per P monico 𝔇/𝔇P ≅ 𝔄^m; (b) 𝒯 è un 𝔇-sottomodulo.

### Quadro
Come OPR2 §3.1: 𝔇 ∈ {𝒟 = A_1[∂_t] (∂_t centrale), A_2}, 𝔄 = elementi di grado 0 in ∂_t, S := 𝔄∖{0}, K corpo dei quozienti di 𝔄, 𝔎 := K[∂_t;δ] = S^{−1}𝔇 (localizzazione di Ore di 𝔇 in S; per 𝒟 è immediato, 𝔎 = K[∂_t]; per A_2 CON-FONTE come in OPR2 §3.1, McConnell–Robson §2.1, numero non verificato). ℱ = C^∞(Ω), Ω connesso; 𝒯 = 𝒯_𝔄 (𝔇-sottomodulo per OP-ALG-L5(b), la cui prova non usa la monicità). Ora P ∈ 𝔇 ha grado m ≥ 1 in ∂_t e coefficiente direttore p_m ∈ 𝔄∖0 qualsiasi: P = Σ_{j≤m}p_j∂_t^j. In 𝔎, P = p_mP̂ con P̂ := p_m^{−1}P monico, quindi 𝔎P = 𝔎P̂ e dim_K𝔎/𝔎P = m (divisione euclidea per P̂ in 𝔎, OPR2-L3(a)). sat(𝔇P) := 𝔎P ∩ 𝔇 ⊇ 𝔇P; 𝔇P è *saturato* se sat(𝔇P) = 𝔇P (⟺ 𝔇/𝔇P senza S-torsione).

### [OPF5B-T2] Teorema (T4 in forma saturata, P qualsiasi) — PROVA SCRITTA
*Tesi.* Per u ∈ ℱ con Pu = 0 sono equivalenti: (a′) Ann_𝔇(u) ⊆ 𝔎P (equivalentemente ⊆ sat(𝔇P)); (b) se Σ_{j<m}b_j∂_t^ju = 0 con b_j ∈ 𝔄 allora tutti i b_j = 0; (c) rank_𝔄(𝔇u) = m; (d′) non esiste Q ∈ 𝔇 ∖ 𝔎P con Qu ∈ 𝒯. Inoltre (e) Ann_𝔇(u) = 𝔇P ⟺ (a′) e Qu ≠ 0 per ogni Q ∈ sat(𝔇P)∖𝔇P; in particolare se 𝔇P è saturato, Ann_𝔇(u) = 𝔇P ⟺ (b) ⟺ (d′), che è OP-ALG-T4 parola per parola. Se P è monico, sat(𝔇P) = 𝔇P (𝔇/𝔇P ≅ 𝔄^m, OP-ALG-L5(a)) e si ritrova T4.
*Prova.* Sia N := Ann_𝔇(u) ⊇ 𝔇P. *Grado.* Gli elementi non nulli di 𝔎P hanno grado ≥ m (𝔎 dominio, grado additivo). *(b)⇒(a′)* (contronominale): sia Q ∈ N∖𝔎P. In 𝔎, Q = AP̂ + Q₀ con deg Q₀ < m, Q₀ ≠ 0. A = b^{−1}A′ con b ∈ S, A′ ∈ 𝔇 (frazioni sinistre); AP̂ = b^{−1}A′p_m^{−1}P, e A′p_m^{−1} = c^{−1}A″ (condizione di Ore), quindi AP̂ = (cb)^{−1}A″P. Allora (cb)Q − A″P = (cb)Q₀ ∈ 𝔇 è non nullo, di grado < m, e sta in N (cbQ ∈ N, A″P ∈ 𝔇P ⊆ N): una relazione non banale Σ_{j<m}b_j∂_t^ju = 0. *(a′)⇒(b):* una relazione non banale R := Σ_{j<m}b_j∂_t^j ∈ N ha grado < m e R ≠ 0, quindi R ∉ 𝔎P. *(a′)⟺(c):* 𝔇u ≅ 𝔇/N; la localizzazione è esatta (S^{−1}𝔇 piatto), quindi K ⊗_𝔄 (𝔇/N) ≅ 𝔎/𝔎N e rank 𝔇u = dim_K𝔎/𝔎N ≤ dim_K𝔎/𝔎P = m, con uguaglianza ⟺ 𝔎N = 𝔎P ⟺ N ⊆ 𝔎P. *(d′)⟺(a′):* se Qu ∈ 𝒯 con Q ∉ 𝔎P, esiste b ∈ S con bQu = 0, e bQ ∉ 𝔎P (b invertibile in 𝔎): N ⊄ 𝔎P. Viceversa un Q ∈ N∖𝔎P ha Qu = 0 ∈ 𝒯. *(e)* è immediato da 𝔇P ⊆ N ⊆ sat(𝔇P). ∎

### [OPF5B-P3] Proposizione (coefficiente direttore funzione) — PROVA SCRITTA
*Ipotesi.* 𝔇 = 𝒟 e p_m = π ∈ ℂ[x]∖0 (operatore di moltiplicazione; per A_2 lo stesso con π ∈ ℂ[t,x]); Ω connesso con π ≠ 0 su Ω. 𝔄_π := ℂ[x,π^{−1}]⟨∂_x⟩ (operatori differenziali in x con coefficienti nel localizzato, che agiscono su C^∞(Ω)); è un dominio noetheriano (filtrazione per ordine con graduato ℂ[x,π^{−1}][ξ]); ogni elemento è π^{−N}b con b ∈ A_1. 𝒟_π := 𝔄_π[∂_t]; P = πP̂, P̂ monico in 𝒟_π.
*Tesi.* (i) 𝒯_{𝔄_π} = 𝒯_{A_1} su C^∞(Ω). (ii) Ann_𝒟(u) = Ann_{𝒟_π}(u) ∩ 𝒟. (iii) 𝒟_πP ∩ 𝒟 = 𝒟P ⟺ M := 𝒟/𝒟P non ha π-torsione (π^NQ ∈ 𝒟P ⇒ Q ∈ 𝒟P). (iv) Se M è senza π-torsione: per Pu = 0, **Ann_𝒟(u) = 𝒟P ⟺ non esiste Q ∈ 𝒟∖𝒟P con Qu ∈ 𝒯 ⟺ (b)** — OP-ALG-T4 vale alla lettera per P non monico. (v) Se M ha π-torsione, **nessuna** soluzione su Ω identifica: Ann_𝒟(u) ⊋ 𝒟P per ogni u ∈ ker P. (vi) M è senza π-torsione ⟺ la moltiplicazione destra per P sul 𝒟-modulo destro 𝒟/π𝒟 è iniettiva.
*Prova.* (i) b = π^{−N}b′, b′f = π^Nbf, e π^N è invertibile su C^∞(Ω). (ii) Definizione. (iii) Q = π^{−N}A′P ∈ 𝒟 con A′ ∈ 𝒟 ⟺ π^NQ = A′P ∈ 𝒟P. (iv) OP-ALG-T4 vale per P̂ su 𝒟_π (𝔄_π noetheriano dominio; la prova di T4 e di L5 usa solo questo). (⇒) Se Ann_𝒟(u) = 𝒟P e A ∈ Ann_{𝒟_π}(u), π^NA ∈ Ann_𝒟(u) = 𝒟P per N grande, quindi A ∈ 𝒟_πP: Ann_{𝒟_π}(u) = 𝒟_πP̂; per T4 nessun Q ∈ 𝒟_π∖𝒟_πP̂ ha Qu ∈ 𝒯, in particolare nessun Q ∈ 𝒟∖𝒟P (che per (iii) non sta in 𝒟_πP). (⇐) Se Ann_𝒟(u) ⊋ 𝒟P, un Q ∈ Ann∖𝒟P non sta in 𝒟_πP (iii) e Qu = 0 ∈ 𝒯. L'equivalenza con (b) è T4 (b)⟺(d) per P̂ (la relazione su 𝔄_π si porta su A_1 moltiplicando per π^N). (v) Se π^NQ = A′P con Q ∉ 𝒟P, per ogni u ∈ ker P: π^NQu = A′Pu = 0, quindi Qu = 0 su Ω (π ≠ 0): Q ∈ Ann_𝒟(u)∖𝒟P. (vi) Se AP = πQ con A ∉ π𝒟, allora Q ∉ 𝒟P (Q = BP darebbe AP = πBP, A = πB: assurdo) e πQ ∈ 𝒟P: π-torsione. Viceversa se π^NQ = AP con Q ∉ 𝒟P e N ≥ 1 minimo: se A = πA_1, cancellando π a sinistra (dominio) π^{N−1}Q = A_1P contro la minimalità (o Q ∈ 𝒟P se N = 1); quindi A ∉ π𝒟 e AP ∈ π𝒟: non iniettiva. ∎

### [OPF5B-C4] Corollario (Bessel radiale) — PROVA SCRITTA
*Dato.* P_r := x∂_t − ∂_x x∂_x = x∂_t − x∂_x² − ∂_x ∈ 𝒟 (calore radiale in 2D, non monico, π = x); u_G := t^{−1}e^{−x²/(4t)}.
*Tesi.* (a) 𝒟/𝒟P_r non ha x-torsione. (b) P_ru_G = 0 e u_G ∉ 𝒯_{A_1}; quindi **Ann_𝒟(u_G) = 𝒟P_r** su ogni aperto connesso Ω ⊂ {t > 0}. (c) I modi u_k = e^{−k²t}J_0(kx) sono di A_1-torsione ((x∂_x² + ∂_x + k²x)u_k = 0): non identificano. (d) In A_2, u_G è di 𝒜-torsione ((2t∂_x + x)u_G = 0): non identifica (come OP-ALG-P5).
*Prova.* (a) Per P3(vi). 𝒟/x𝒟 ha base {∂^iT^k} (T := ∂_t; ogni elemento è Σx^a∂^iT^k e i termini con a ≥ 1 stanno in x𝒟), e lo si identifica con ℂ[η,T], ∂^iT^k ↦ η^iT^k. Azione destra: ∂^i·x = x∂^i + i∂^{i−1} ≡ i∂^{i−1}, quindi ·x agisce come ∂_η; ·∂ come moltiplicazione per η; ·T come moltiplicazione per T. Allora f·P_r = f·(xT) − f·(∂x∂) = T∂_ηf − η∂_η(ηf) = Tf′ − ηf − η²f′ (SymPy D3, normal ordering esatto nell'algebra di Weyl). Se f = Σ_{i≤d}c_i(T)η^i con c_d ≠ 0, il coefficiente di η^{d+1} in f·P_r è −c_d − dc_d = −(d+1)c_d ≠ 0 (Tf′ ha grado ≤ d−1): la mappa è iniettiva (SymPy D4: nucleo nullo su grado ≤ 8 in η, ≤ 3 in T). (b) P_ru_G = 0: calcolo (SymPy D1). Se b = Σ_{j≤r}β_j(x)∂_x^j ∈ A_1, β_r ≠ 0, annullasse u_G su un aperto di {t>0}: con s := 1/t, ∂_x^je^{−sx²/4} = h_j(x,s)e^{−sx²/4}, h_0 = 1, h_{j+1} = ∂_xh_j − (sx/2)h_j, quindi h_j = (−sx/2)^j + (termini di grado < j in s); H := Σ_jβ_jh_j ha coefficiente di s^r uguale a β_r(x)(−x/2)^r ≢ 0, e H(x,1/t) = 0 su un aperto: H ≡ 0, assurdo (SymPy D5, controllo su ordine e grado ≤ 3). Quindi u_G ∉ 𝒯_{A_1} = 𝒯_{𝔄_x}, che per m = 1 è la condizione (b). Su Ω′ := Ω ∩ {x ≠ 0} (aperto non vuoto; si lavora su una componente connessa) P3(iv) con (a) dà Ann_𝒟(u_G) = 𝒟P_r su Ω′; poiché Ann su Ω ⊆ Ann su Ω′ e 𝒟P_r ⊆ Ann su Ω, l'uguaglianza vale su Ω. (c) Equazione di Bessel di ordine 0 per J_0(kx) (SymPy D6). (d) ∂_xu_G = −(x/2t)u_G. ∎
*Lettura.* Il V-ex di S5-EX (E6.3e, box(3,3)) è ora un teorema. La riga S5-EX "l'ipotesi monico non è soddisfatta" si risolve: per π funzione, T4 vale alla lettera se e solo se 𝒟/𝒟P è senza π-torsione (test effettivo P3(vi)). Per p_m operatore (non funzione) resta la forma saturata T2.
