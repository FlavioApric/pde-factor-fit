**Rejection memo: OPF-T5 / P5 / O1**

The closing claims ("Esito P2-Q1": the problem "chiuso" with density "per ogni P (quasi) omogeneo", and "nessuna somma è chiusa senza essere densa" in these classes) are not proved by OPF-T5. T5 gives nothing unless condition (C), Φ_λ(Ω̄) ⊂ Ω, holds. For quasi-homogeneous P with unequal weights, the symmetry group allows almost no domains. Take the beam τ²+ξ⁴ = (τ+iξ²)(τ−iξ²). A linear A near I with P(A^T z) = κP(z) must fix each factor, which forces A = diag(b², b). For b near 1 the displacement of a point y is −(1−b)W(y−o), with W = diag(2,1). Now take the convex parallelogram Ω = {0<t<L, t<x<t+1}. Keeping this displacement inward on the top edge forces L ≤ 2t_o − x_o + 1. On the bottom edge it forces 0 ≥ 2t_o − x_o. Together these give L ≤ 1. So for L > 1, (C) fails for every centre o. That is the same characteristic parallelogram that OPF-P5 itself works in. Corollary (b) is therefore limited to rectangles, not "every (quasi) homogeneous P". The transport extension of P5 likewise needs nested chords (rectangles with |J| ≥ |c||I|). The domain-free summary claim is unproved.

OPF-O1 is overclaimed in the same way. The memo says the method's obstruction is "dimostrata", but O1 only rules out unweighted linear changes of variables. Weighted affine maps w ↦ e^{a·y}(w∘Φ) are just as usable. For P = (τ−ξ²)(τ+ξ) there is a nontrivial one: v = e^{t−x} w(t, 2t−x) satisfies v_t − v_xx = e^{t−x}(w_t − w_xx)∘Φ and v_t + v_x = e^{t−x}(w_t + w_x)∘Φ. So "only translations" is false for the class the method actually uses. "Obstruction demonstrated" and "closed with density in these classes" must be withdrawn.
