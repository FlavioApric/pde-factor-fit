## 1. OPF-Q1 — calore × trasporto
### Esplorazione
Il difetto di regolarità di una scomposizione u = u_1 + F(x − ct) sta solo dove le corde del trasporto degenerano: sul rettangolo con c > 0 i due angoli C₁ = (0,b) e C₂ = (T,a). Vicino a C₁ una traslazione y ↦ y + τ₁, τ₁ = (h,−k), h,k > 0, manda Ω̄ ∩ (intorno di C₁) dentro Ω ed è una simmetria di P. Non si può tagliare u con una funzione di (t,x), ma si possono tagliare separatamente: la parte di trasporto con funzioni di s = x − ct (commutano con ∂_t + c∂_x), la parte di calore con un taglio θ(t,x) seguito da una correzione z che risolve un problema del calore con dato in forma di divergenza (guadagno di una derivata). OPF-O1 (e la sua estensione pesata, AUDIT_OP-FUN O1-1) esclude simmetrie **globali**: qui le simmetrie sono locali e la colla è diversa nei due fattori.

### [OPR2-L0] Lemma (problema del calore con sorgente in forma di divergenza) — PROVA SCRITTA
*Ipotesi.* T′ > 0, G_0, G_1 ∈ H^m(ℝ²) (m ≥ 0) nulle per t ≤ −1 + η (η > 0). *Tesi.* z definita da ẑ(t,ξ) := ∫_{−1}^t e^{−(t−r)ξ²}(Ĝ_0 + iξĜ_1)(r,ξ)dr (trasformata in x) verifica z_t − z_xx = G_0 + ∂_xG_1 in 𝒟′((−1,T′)×ℝ) e ‖z‖_{H^m((−1,T′)×ℝ)} ≤ C(T′)(‖G_0‖_{H^m} + ‖G_1‖_{H^m}).
*Prova.* Per ξ fisso ẑ(·,ξ) = K_0 *_t Ĝ_0 + K_1 *_t Ĝ_1 con K_0(t) = e^{−tξ²}1_{(0,T′+1)}, K_1 = iξK_0. ‖K_0‖_{L¹} = (1 − e^{−(T′+1)ξ²})/ξ² ≤ T′+1 e ‖K_1‖_{L¹} = (1 − e^{−(T′+1)ξ²})/|ξ| ≤ min((T′+1)|ξ|, 1/|ξ|) ≤ √(T′+1) (SymPy A3). Young in t e Plancherel in x: ‖z‖_{L²} ≤ (T′+1)‖G_0‖ + √(T′+1)‖G_1‖. Per |α| ≤ m: ∂_x^j commuta con la formula (moltiplicatore (iξ)^j); ∂_t commuta con la convoluzione di Duhamel perché le G_i sono nulle vicino a r = −1 (integrazione per parti in r): ∂^αz è la z costruita con ∂^αG_0, ∂^αG_1; si applica la stima L². L'equazione: derivando la formula, ∂_tẑ = −ξ²ẑ + Ĝ_0 + iξĜ_1. ∎

### [OPR2-T1] Teorema (densità per calore × trasporto) — PROVA SCRITTA
*Ipotesi.* Ω = (0,T)×(a,b), c ∈ ℝ, m ≥ 0 intero, P = (τ − ξ²)(τ + cξ), 𝓗_1 := ker_{H^m(Ω)}(∂_t − ∂_x²), 𝓗_2 := ker_{H^m(Ω)}(∂_t + c∂_x).
*Tesi.* 𝓗_1 + 𝓗_2 è denso in ker_{H^m(Ω)}P. Quindi (C12-P7(a)) le componenti di ogni u ∈ ker_{H^m}P stanno in H^m ⟺ la somma è chiusa ⟺ γ_2 > 0 ⟺ c_F(𝓗_1,𝓗_2) < 1.
*Dipendenze.* C12-T1′ (DIMOSTRATO); ipoellitticità del calore (CON-FONTE classico: Hörmander, ALPDO II, cap. 11; numero non verificato); operatore d'estensione H^m(Ω) → H^m(ℝ²) per il rettangolo (CON-FONTE: Stein, *Singular Integrals*, cap. VI §3, oppure riflessione d'ordine m; numero non verificato); OPF-T5(b) per c = 0; OPR2-L0.
*Prova.* **c = 0:** P = (τ−ξ²)τ è quasi omogeneo con pesi (2,1); OPF-T5(b). **c < 0:** la riflessione x ↦ a + b − x conserva il calore e cambia c in −c. Sia dunque **c > 0**, s := x − ct, S := (a − cT, b) l'insieme dei valori di s su Ω, C₁ := (0,b) (unico punto di Ω̄ con s = b), C₂ := (T,a) (unico con s = a − cT).
*Passo 1 (struttura).* Sia u ∈ ker_{H^m}P. Per C12-T1′ (Ω convesso) u = u_1 + u_2 in 𝒟′(Ω), (∂_t − ∂_x²)u_1 = 0, (∂_t + c∂_x)u_2 = 0. u_1 ∈ C^∞(Ω) (ipoellitticità). u_2 = F(s) con F ∈ 𝒟′(S) (nelle coordinate (t,s), ∂_t|_s u_2 = 0 su un aperto con fette in t connesse).
*Passo 2 (F ∈ H^m_loc(S)).* Fissato s₀ ∈ S, la corda {t : (t, s+ct) ∈ Ω} contiene un intervallo [α,β] per s in un intorno N di s₀, con {(t, s+ct) : t ∈ [α,β], s ∈ N̄} ⊂ Ω compatto. Sia ψ ∈ C_c^∞((α,β)), ∫ψ = 1. Per φ ∈ C_c^∞(N), accoppiando con ψ(t)φ(x − ct) (cambio (t,s) ↦ (t,x), jacobiano 1): ⟨F, φ⟩ = ⟨A − B, φ⟩ con A(s) := ∫u(t,s+ct)ψ(t)dt, B(s) := ∫u_1(t,s+ct)ψ(t)dt. B ∈ C^∞(N); ∂_s^jA = ∫(∂_x^ju)(t,s+ct)ψ dt ∈ L²(N) per j ≤ m (Fubini, Cauchy–Schwarz). Dunque F ∈ H^m(K) per ogni compatto K ⊂ S. Conseguenze: per ogni compatto K ⊂ S, u_2 = F∘s ∈ H^m(Ω_K), Ω_K := Ω ∩ {s ∈ int K} (∂_t^i∂_x^j(F∘s) = (−c)^iF^{(i+j)}∘s, corde di lunghezza ≤ T), e u_1 = u − u_2 ∈ H^m(Ω_K).
*Passo 3 (scelte).* Si sceglie r > 0 con B(C₁,3r) ∩ B(C₂,3r) = ∅ e B(C_i,3r) lontano dagli altri due vertici; poi δ > 0 con {s > b − δ} ∩ Ω ⊂ B(C₁,r) e {s < a − cT + δ} ∩ Ω ⊂ B(C₂,r) (il triangolo {s > b − δ} ∩ Ω ha vertici C₁, (0,b−δ), (δ/c,b)). Siano θ_i ∈ C_c^∞(B(C_i,2r)), θ_i = 1 su B(C_i,r); χ_1(s) liscia, = 1 per s ≥ b − δ/2, = 0 per s ≤ b − δ; χ_2 analoga in a − cT. Per ε ∈ (0,ε₀): τ₁ := (ε, −ε), τ₂ := (−ε, ε). Allora: (a) per y ∈ Ω̄ ∩ B̄(C₁,3r), y + τ₁ ∈ Ω e anzi {y + τ₁} è un compatto di Ω (t + ε ≥ ε, x − ε ≤ b − ε, e le altre disuguaglianze valgono per r, ε piccoli); analogamente per C₂. (b) s(y + τ₁) = s(y) − σ, s(y + τ₂) = s(y) + σ, σ := ε(1 + c) > 0 (SymPy A2). (c) (∂_t − ∂_x²) e (∂_t + c∂_x) commutano con le traslazioni.
*Passo 4 (approssimante).* Siano w_i := u_1∘(·+τ_i) − u_1 su Ω ∩ B(C_i,3r), e
 ũ_2 := (1 − χ_1 − χ_2)(s)F(s) + χ_1(s)F(s − σ) + χ_2(s)F(s + σ),

*Passo 5 (ũ_2 ∈ 𝓗_2).* ũ_2 è funzione di s, quindi nel nucleo del trasporto. Ogni addendo è in H^m(S) come funzione di s: (1−χ_1−χ_2)F ha supporto in [a−cT+δ/2, b−δ/2] dove F ∈ H^m; χ_1(s)F(s−σ) usa F su [b−δ−σ, b−σ] ⊂ S compatto; idem per χ_2. Quindi ũ_2 ∈ H^m(Ω).
*Passo 6 (ũ_1 ∈ 𝓗_1).* Calore: con H := ∂_t − ∂_x², H(θw) = θHw + (∂_tθ + ∂_x²θ)w − 2∂_x(∂_xθ·w) (SymPy A1), e Hw_i = 0 dove definita. Quindi H(u_1 + Σθ_iw_i) = g_0 + ∂_xg_1 = H z su Ω: Hũ_1 = 0. Regolarità: ũ_1 = (1 − θ_1 − θ_2)u_1 + Σθ_i·u_1∘(·+τ_i) − z. Il primo termine ha supporto fuori da B(C₁,r) ∪ B(C₂,r), dove s ∈ [a−cT+δ, b−δ]: H^m per il Passo 2. θ_i·u_1∘(·+τ_i) è C^∞ fino al bordo su supp θ_i ∩ Ω̄ (Passo 3(a), u_1 ∈ C^∞(Ω)). g_0, g_1 ∈ H^m(Ω): supp ∇θ_i ∩ Ω ⊂ (B(C_i,2r)∖B(C_i,r)) ∩ Ω, dove s ∈ K compatto di S e anche s ∓ σ ∈ K′ compatto: w_i ∈ H^m lì. z ∈ H^m per OPR2-L0. *Passo 7 (v → u in H^m per ε → 0).* Su Ω ∩ B(C₁,2r), u∘(·+τ₁) = u_1∘(·+τ₁) + F(s − σ), quindi
