## 3. P4-Q-min: minimalità del maggiorante
### 3.1 Ordine dei dati
**[OP-ALG-D2].** Fissati P ∈ K[τ,ξ] non costante (con fattorizzazione come in D1(v)), Ω e p₀, sia 𝒰 la classe delle u reali-analitiche su Ω con P(∂)u = 0 e getti in p₀ in K (modello M2⁺ di P4 §6: oracoli J (getti) e Z (test di zero di Q(∂)u, Q ∈ K[τ,ξ])). Un **dato** è una relazione totale 𝒜 ⊆ 𝒰 × ℕ (insieme dei valori validi di 𝒜 per u, non vuoto). 𝒜 ≤ 𝒞 (𝒜 **non più forte di** 𝒞) se esiste un algoritmo a oracoli che, per ogni u ∈ 𝒰 e ogni valore valido c di 𝒞 per u, ricevendo (P, c) e gli oracoli di u termina con un valore valido di 𝒜 per u. ≡ := ≤ nei due sensi; < := ≤ e non ≥. 𝒜 è **sufficiente** se χ ≤ 𝒜. Dati:
- χ: χ(u) = 1 se Ann(u) = (P), 0 altrimenti (codificato in ℕ).
- 𝔇: D valido se [Ann(u) ≠ (P) ⇒ ∃Q ∈ Ann(u)∖(P), deg Q ≤ D].
- 𝔅: B valido se B ≥ dim_ℂ(R·u ∩ EP(Ω)).
- 𝔊: un codice di G ∈ K[τ,ξ] valido se G ∼ G_u (G_u ∼ ∏P_i^{f_i} ha un rappresentante in K[τ,ξ]).

### [OP-ALG-T3] Risposta a P4-Q-min — PROVA SCRITTA
*Tesi.* (a) χ ≡ 𝔇. (b) 𝒜 è sufficiente ⟺ χ ≤ 𝒜: χ (equivalentemente 𝔇) è il **minimo** dei dati sufficienti; nessun dato strettamente più debole di χ è sufficiente. (c) 𝔅 ≡ 𝔊. (d) χ ≤ 𝔅. (e) Se P è irriducibile e ridotto (r = 1, e_1 = 1): 𝔅 ≡ χ. (f) Se Σ_ie_i ≥ 2: esistono Ω ∋ 0 e p₀ = 0 tali che **𝔅 ≰ χ** su 𝒰(P,Ω,0), quindi χ < 𝔅: il maggiorante B è strettamente più forte del dato minimo.
*Prova.*
(a) *χ ≤ 𝔇:* dato D, sia N := max(D, deg P): Ann(u) = (P) ⟺ dim(Ann(u) ∩ R_{≤N}) = dim((P) ∩ R_{≤N}) (⇐ perché un testimone avrebbe grado ≤ D ≤ N; ⇒ ovvio); il primo membro si calcola con P4-T4(i). *𝔇 ≤ χ:* se χ = 1 si restituisce 0 (valido: la premessa è falsa); se χ = 0 si esegue la semi-decisione P4-T4(ii), che termina perché Ann(u) ≠ (P), al primo n con dim(Ann(u) ∩ R_{≤n}) > dim((P) ∩ R_{≤n}); si restituisce n (esiste un testimone di grado ≤ n).
(b) Se 𝒜 è sufficiente, l'algoritmo che decide calcola χ da 𝒜: χ ≤ 𝒜. Viceversa χ ≤ 𝒜 è la definizione. Se 𝒞 < χ non può essere sufficiente (sarebbe χ ≤ 𝒞 ≤ χ... cioè 𝒞 ≡ χ, contro <).
(c) *𝔊 ≤ 𝔅:* P4-T4(iii) (DIMOSTRATO) calcola G_u da B. *𝔅 ≤ 𝔊:* dato G ∼ G_u, sia w₀ := G(∂)u; R·u ∩ EP = R·w₀ (P4-T2(iii)) e w₀ ∈ EP. Gli oracoli di w₀ si ottengono da quelli di u (getti: Leibniz; zero: Q′(∂)w₀ = 0 ⟺ (Q′G)(∂)u = 0). Per n = 1, 2, …: si calcolano Ann(w₀) ∩ ℂ[τ]_{≤n} e Ann(w₀) ∩ ℂ[ξ]_{≤n} (P4-T4(i)); poiché w₀ ∈ EP esistono a(τ), b(ξ) non nulli in Ann(w₀) (C3-L3(c)), e la ricerca termina. R·w₀ ≅ R/Ann(w₀) è quoziente di R/(a(τ),b(ξ)) ≅ ℂ[τ]/(a) ⊗ ℂ[ξ]/(b): B := deg a·deg b è valido.
(d) P4-T4(iii) (DIMOSTRATO).
(e) *𝔅 ≤ χ:* se χ = 1, Ann(u) = (P) è principale, quindi R·u ∩ EP = 0 (P4-T2(v)(a)) e B = 0 è valido. Se χ = 0: C3-T1(a) con r = 1, e_1 = 1 (P/P_1 = costante) dà u ∈ EP; si procede come in (c) con w₀ := u. Con (d): 𝔅 ≡ χ.
(f) Sia P = c∏_{i=1}^rP_i^{e_i} con Σe_i ≥ 2 e P̃ := P/P_1 (non costante). *Istanza base.* Per P4-L7 (DIMOSTRATO) applicato a P̃ esistono Ω = (−ε,ε)², p₀ = 0 e ũ reale-analitica su Ω con P̃(∂)ũ = 0, getti in K, Ann(ũ) = (P̃). Si sceglie z₀ ∈ V(P_1) ∩ K² con ∇P_1(z₀) ≠ 0 e P_j(z₀) ≠ 0 per j ≠ 1 (si escludono insiemi finiti di V(P_1), che ha infiniti punti in K²: Fatto (F), Passo 1 di P4-T5, Fatto (V)), η₀ ∈ {e₁,e₂} con ∇P_1(z₀)·η₀ ≠ 0, s := ⟨η₀,y⟩ e e := s^{e_1−1}e^{⟨z₀,y⟩}. Sui polinomi in s, P_1(z₀+∂) abbassa il grado esattamente di 1 (coefficiente direttore moltiplicato per ∇P_1(z₀)·η₀ ≠ 0, come in C3-P1[M2] passo 2) e P_j(z₀+∂), j ≠ 1, conserva il grado: quindi P(∂)e = 0 e P̃(∂)e = κe^{⟨z₀,y⟩} con κ ≠ 0. Sia u := ũ + e ∈ 𝒰. *χ(u) = 0:* w_1 = (P/P_1)(∂)u = P̃(∂)ũ + κe^{⟨z₀,·⟩} = κe^{⟨z₀,·⟩} ∈ EP (C3-T1(a)). *Ann(u) ⊆ (P̃):* se Q ∈ Ann(u), Q(∂)ũ = −Q(∂)e ∈ EP ∩ R·ũ = 0 (P4-T2(v)(a): Ann(ũ) principale ⟺ R·ũ ∩ EP = 0), quindi Q ∈ Ann(ũ) = (P̃). (Inoltre Ann(u) = P̃·𝔪_{z₀}, G_u = P̃, dim(R·u ∩ EP) = 1: non serve.)
*Avversario.* Sia 𝔄 un algoritmo che pretende 𝔅 ≤ χ. Su (P, χ = 0) e gli oracoli di u termina con un B, avendo interrogato getti d'ordine ≤ k₀ e il test di zero su un insieme finito 𝒬. Sia N₀ := dim R_{≤k₀}, 𝒬′ := 𝒬∖(P̃). Per P4-T5 (Passi 2–3, DIMOSTRATO) applicato a (P̃, ũ): esiste v₁ ∈ E^K_{P̃} (combinazione K-lineare di funzioni g_{i,z,j} ∈ ker P̃ ∩ EP con z ∈ K²) con J_{k₀}(v₁) = J_{k₀}(ũ), e per ogni Q ∈ 𝒬′ esiste e_Q ∈ E^K_{P̃} con J_{k₀}(e_Q) = 0 e Q(∂)e_Q ≠ 0. Sia F ⊂ V(P̃_1) ∩ K² (P̃_1 un fattore irriducibile di P̃) un insieme di |F| > B + N₀ punti distinti da tutti gli esponenti che compaiono in v₁, negli e_Q e da z₀ (possibile: V(P̃_1) ∩ K² è infinito); per z ∈ F, e^{⟨z,·⟩} ∈ ker P̃. S_F := {c ∈ K^F : J_{k₀}(Σ_zc_ze^{⟨z,·⟩}) = 0}, dim S_F ≥ |F| − N₀; supp(S_F) := {z : S_F ⊄ {c_z = 0}} ha almeno dim S_F elementi (la proiezione di S_F sulle coordinate di supp è iniettiva). Per parametri (λ, c) ∈ K^{𝒬′} × S_F poniamo
  u′ := v₁ + Σ_{Q∈𝒬′}λ_Qe_Q + Σ_{z∈F}c_ze^{⟨z,·⟩} + e.
Allora u′ ∈ EP, P(∂)u′ = 0 (tutti gli addendi tranne e stanno in ker P̃ ⊆ ker P), getti in K, J_{k₀}(u′) = J_{k₀}(ũ) + J_{k₀}(e) = J_{k₀}(u). *Risposte di zero.* Se Q ∈ 𝒬 ∩ (P̃): Q(∂) annulla ker P̃, quindi Q(∂)u′ = Q(∂)e = Q(∂)u. Se Q ∈ 𝒬′: Q(∂)u ≠ 0 (Ann(u) ⊆ (P̃)); l'insieme dei parametri con Q(∂)u′ = 0 è un sottospazio affine (dipendenza affine) proprio, perché spostando λ_Q di 1 Q(∂)u′ cambia di Q(∂)e_Q ≠ 0. Le condizioni c_z ≠ 0 (z ∈ supp(S_F)) escludono sottospazi propri di S_F. Un'unione finita di sottospazi affini propri non ricopre K^{𝒬′} × S_F (K infinito): esistono parametri con Q(∂)u′ ≠ 0 per ogni Q ∈ 𝒬′ e c_z ≠ 0 per ogni z ∈ supp(S_F). Per tali parametri u′ ∈ 𝒰 dà le stesse risposte di u a tutte le interrogazioni di 𝔄 (getti d'ordine ≤ k₀, zero su 𝒬), e χ(u′) = 0 (u′ ∈ EP, C3-C2): l'esecuzione di 𝔄 su (P, 0) con gli oracoli di u′ è identica (induzione sulle interrogazioni) e restituisce lo stesso B. *Ma B non è valido per u′:* gli esponenti z ∈ supp(S_F) compaiono in u′ con coefficiente c_z ≠ 0 (F è disgiunto dagli altri esponenti), quindi V(Ann u′) ⊇ supp(S_F) (C3-L3(c)) e dim(R·u′ ∩ EP) = dim R·u′ = dim R/Ann(u′) ≥ |V(Ann u′)| ≥ |F| − N₀ > B (R/Ann(u′) si surietta su ∏_{z∈V(Ann u′)}R/𝔪_z, teorema cinese). Contraddizione: nessun algoritmo calcola un B valido da χ. ∎
