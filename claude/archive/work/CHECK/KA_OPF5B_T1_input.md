### Notazione
Simbolo: p(ζ) := P(iζ), ζ ∈ ℝ², così P(∂)e^{iy·ζ} = p(ζ)e^{iy·ζ}. p^{(α)} := ∂_ζ^α p. P̃(ζ) := (Σ_α|p^{(α)}(ζ)|²)^{1/2} (somma finita; P̃ ≥ c_P > 0 perché la derivata d'ordine massimo di un monomio direttore è una costante non nulla). k_m(ζ) := (1+|ζ|²)^{m/2}. Per un peso k > 0 misurabile, B_{2,k} := {f ∈ 𝒮′ : kf̂ ∈ L²}, ‖f‖_{2,k} := ‖kf̂‖_{L²}; B_{2,k_m} = H^m(ℝ²) con norma equivalente; B_{∞,k}: sup|kf̂| < ∞. Un peso k è **temperato** se k(ζ+η) ≤ C(1+|η|)^N k(ζ) per ogni ζ, η.

### [OPF5B-L1] Lemma (pesi) — PROVA SCRITTA
(a) P̃ e 1/P̃ sono temperati: P̃(ζ+η) ≤ C_P(1+|η|)^d P̃(ζ), d = deg P. (b) |p^{(α)}(ζ)| ≤ P̃(ζ) per ogni α; quindi, con k := k_m/P̃ (temperato), P^{(α)}(∂) è limitato B_{2,k_m} → B_{2,k} con norma ≤ 1 (a meno della costante i^{|α|}). (c) Se k è temperato e φ ∈ C_c^∞(ℝ²), f ↦ φf è limitato su B_{2,k}. (d) Se φE ∈ B_{∞,P̃} e g ∈ B_{2,k} ha supporto compatto, (φE)*g ∈ B_{2,kP̃} con ‖(φE)*g‖_{2,kP̃} ≤ sup|P̃\widehat{φE}|·‖g‖_{2,k}.
*Prova.* (a) Taylor del polinomio p^{(α)}: p^{(α)}(ζ+η) = Σ_{|β|≤d}p^{(α+β)}(ζ)η^β/β!, quindi |p^{(α)}(ζ+η)| ≤ P̃(ζ)Σ_{|β|≤d}|η|^{|β|}/β! ≤ C(1+|η|)^dP̃(ζ); somma in ℓ² su α (finiti). Scambiando ζ ↔ ζ+η e η ↔ −η si ottiene P̃(ζ) ≤ C(1+|η|)^dP̃(ζ+η), cioè la temperanza di 1/P̃. k_m è temperato (Peetre: (1+|ζ+η|²) ≤ 2(1+|ζ|²)(1+|η|²)), e un prodotto di pesi temperati lo è. (SymPy A2: rapporto massimo 0.038 su 400 campioni per la trave.) (b) Per definizione di P̃; ‖P^{(α)}(∂)f‖_{2,k} = ‖k|p^{(α)}|f̂‖ ≤ ‖kP̃f̂‖ = ‖k_mf̂‖. (c) \widehat{φf} = (2π)^{−2}φ̂*f̂; con k(ζ) ≤ C(1+|η|)^Nk(ζ−η): k(ζ)|\widehat{φf}(ζ)| ≤ (2π)^{−2}C∫|φ̂(η)|(1+|η|)^Nk(ζ−η)|f̂(ζ−η)|dη; Young: ‖φf‖_{2,k} ≤ (2π)^{−2}C‖(1+|η|)^Nφ̂‖_{L¹}‖f‖_{2,k}. (d) \widehat{(φE)*g} = \widehat{φE}·ĝ (convoluzione di una distribuzione a supporto compatto con una distribuzione a supporto compatto); kP̃|\widehat{φE}ĝ| ≤ sup|P̃\widehat{φE}|·k|ĝ|. ∎
