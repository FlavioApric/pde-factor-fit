#### [P4-T2] Teorema spettrale del modulo ciclico — PROVA SCRITTA
*Ipotesi.* Ω aperto connesso, u ∈ D′(Ω), I := Ann(u) ≠ 0, I = G·J con G = G_u = gcd(I) e V(J) finito (C3-L2). W = R·u ≅ R/I.
*Tesi.*
(i) σ_χ(u) = V(I) = V(G) ∪ V(J).
(ii) Ogni autovettore congiunto di W relativo a z è c·e^{⟨z,·⟩}|_Ω (c ≠ 0); ogni autovettore generalizzato sta in EP(Ω). **σ_p(u) = V(J)** (insieme finito).
(iii) **W ∩ EP(Ω) = G(∂)W = R·G(∂)u**; è la somma degli autospazi generalizzati congiunti di W ed è isomorfo come R-modulo a R/J tramite Q̄ ↦ (QG)(∂)u; dim_ℂ(W ∩ EP) = dim_ℂ R/J < ∞.
(iv) Successione esatta di R-moduli 0 → R/J →(·G) R/I → R/(G) → 0; nell'identificazione W ≅ R/I l'immagine del primo termine è W ∩ EP, quindi W/(W ∩ EP) ≅ R/(G). Il quoziente R/(G) non ha autovettori congiunti e ha spettro dei caratteri V(G).
(v) **Dicotomia.** (a) Ann(u) principale ⟺ J = R ⟺ σ_p(u) = ∅ ⟺ W ∩ EP = 0. In particolare, se **u identifica (Ann(u) = (P), P non costante), W non ha autovettori congiunti né generalizzati.** (b) W è generato da autovettori generalizzati ⟺ u ∈ EP(Ω) ⟺ G ∼ 1. In tal caso W = ⊕_{z∈V(I)} W_z (somma finita di autospazi generalizzati), i proiettori spettrali Π_z sono polinomi in A_u, B_u e, per ogni L ∈ R,
  ρ_u(L) = Σ_{z∈V(I)} Π_z·L(z + N_z),  con N_z := (A_u − τ_z, B_u − ξ_z)|_{W_z} nilpotente e L(z + h) = Σ_α ∂^αL(z)h^α/α! (somma finita).
  Inoltre ρ_u(L) = Σ_z L(z)Π_z per ogni L ("Â = Σ λ e⊗e^†") ⟺ I è radicale ⟺ u = Σ_k c_ke^{⟨z_k,·⟩} con c_k costanti. (c) Per P non costante, "W generato da autovettori generalizzati" e "Ann(u) = (P)" si escludono (C3-C2).

#### [P4-C2] La parte EP non è un addendo diretto — PROVA SCRITTA (controesempio)
*Enunciato confutato.* "W = (W ∩ EP) ⊕ W′ con W′ sottomodulo (stabile per ∂_t, ∂_x)."
*Dato.* Ω = (0,1)×(−1,1), u = t + f(x) con f ∈ C^∞(−1,1) non EP (per esempio f = e^{x²}: ∂_x^kf = p_k(x)e^{x²} con deg p_k = k, quindi dim ℂ[∂]f = ∞).
*Tesi.* (a) Ann(u) = (τ², τξ), G_u = τ, J_u = (τ,ξ), W ∩ EP = ℂ·1, σ_p(u) = {0}. (b) Non esiste un R-sottomodulo W′ ⊂ W con W = ℂ·1 ⊕ W′.
*Prova.* (a) Scriviamo Q = Q₀(ξ) + τQ₁(ξ) + τ²Q₂(τ,ξ). Q(∂)u = Q₀(0)t + Q₀(∂_x)f + Q₁(0), perché ∂_xt = 0, ∂_tu = 1, ∂_t²u = 0 e ∂_x1 = 0. È nullo ⟺ Q₀(0) = 0 (coefficiente di t; le altre parti non dipendono da t) e Q₀(∂_x)f = −Q₁(0). Se Q₀ ≠ 0, ξQ₀(ξ) annullerebbe f e f sarebbe EP (in una variabile, R4-T1/C3-L3): assurdo. Quindi Q₀ = 0, poi Q₁(0) = 0, cioè Q ∈ (τ², τξ); il viceversa è diretto. gcd(τ², τξ) = τ, J = (τ,ξ) = 𝔪_0, V(J) = {0}, W ∩ EP = R·∂_tu = ℂ·1 (P4-T2(iii)). (b) Se W = ℂ·1 ⊕ W′ con W′ stabile per ∂_t, scriviamo u = c + w′ con w′ ∈ W′: ∂_tw′ = ∂_tu = 1 ∈ W′ ∩ ℂ·1 = 0, assurdo. ∎ SymPy C2a (Ann ∩ R_{≤3} = (τ²,τξ)_{≤3}, dimensione 5), C2b.
*Lettura.* Anche quando c'è una parte spettrale (EP), in generale non si stacca dalla parte "continua" con un proiettore che commuta con le derivate. È l'analogo, dentro un solo modulo ciclico, dell'ostruzione Ext¹ della scomposizione per fattori (RT-R2b).
