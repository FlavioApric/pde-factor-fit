# KA OPF-T4 — Thread 1 (memo d'attacco, subagente Claude fresco a7dab0ba5d327a361, 26/10/2026), verbatim

**Rejection memo: OPF-T4**

Part (iii) claims an explicit construction: "Un elemento di ker ι produce esplicitamente un u ∈ ker P non scomponibile." The proof only supports this for decomposable tensors [θ]⊗(w_j). It takes one multivalued primitive φ and one fixed (w_j) ∈ N, forms g_j = Q_j(∂)(φw_j), assumes each g_j lies in Q_j(∂)A(Ω), and sets u = −Σα_j.

ker ι is a subspace of H^1(Ω;C)⊗N. Once δ(P) ≥ 2 and b_1(Ω) ≥ 2, nothing in the proof shows that ker ι is spanned by decomposable tensors that themselves lie in ker ι. An element Σ_k[θ_k]⊗n_k can satisfy ι(·) = 0 while no single summand does. The construction does not apply to such an element. The closing sentence of (iii), "non nulla se [θ]≠0 e (w_j)≠0", also addresses only the decomposable case. So the explicit inverse of coker Σ_Ω ≅ ker ι, which (iii) advertises, is not proved, and (iv)(e) is a valid instance only because δ(τξ) = 1.

Part (ii) does not rescue (iii). It gives an abstract isomorphism from the long exact sequence. It does not say that the abstract preimage of a general kernel element is the function −Σα_j built in (iii). Each g_j = Σ_k Q_j(φ_k n_{k,j}) must be shown to be monodromic, and the identity Σ_jΣ_k φ_k n_{k,j} = 0 must be used, before u's connecting class can be identified. None of this is written.

The "Esito" therefore overclaims. It calls the criterion "chiuso" and "esplicito", but the explicit half is only established on decomposable tensors.
