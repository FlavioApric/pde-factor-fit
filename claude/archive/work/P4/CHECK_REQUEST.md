#### [P4-T1] Restrizione = annullatore nel caso commutativo — PROVA SCRITTA (elementare)
*Ipotesi.* Ω aperto connesso, u ∈ D′(Ω), W = R·u.
*Tesi.* (i) ρ_u è un omomorfismo unitario di ℂ-algebre, con **ker ρ_u = Ann(u)** e ρ_u(R) ≅ R/Ann(u); inoltre ρ_u(Q) = 0 ⟺ Q(∂)u = 0, e ρ_u(Q) = Q(A_u, B_u).
(ii) Per ogni sottospazio 𝓛 ⊆ R: ρ_u|_𝓛 è iniettiva ⟺ Ann(u) ∩ 𝓛 = 0, e ker(ρ_u|_𝓛) = Ann(u) ∩ 𝓛. Se dim 𝓛 < ∞: u identifica in 𝓛 a meno di scala (dim(Ann(u) ∩ 𝓛) = 1) ⟺ rank(ρ_u|_𝓛) = dim 𝓛 − 1.
(iii) (Classi affini.) Sia 𝓐 = L₀ + 𝓛₀ (𝓛₀ sottospazio) e L* ∈ 𝓐 ∩ Ann(u). Allora 𝓐 ∩ Ann(u) = L* + ker(ρ_u|_{𝓛₀}): L* è l'unico elemento di 𝓐 che annulla u ⟺ ρ_u|_{𝓛₀} è iniettiva. Esempio: 𝓔_n = τ + ℂ[ξ]_{≤n} (evoluzioni u_t = b(∂_x)u, deg b ≤ n): b è compatibile con u ⟺ b(B_u) = A_u.
(iv) (Legame con Gram.) Se u ∈ H^m(Ω) e 𝓛 = span(A) con monomi di ordine ≤ m, allora ker(ρ_u|_𝓛) è il nucleo della Gram 𝔾′ di C3-L1, nelle coordinate dei monomi.
*Strategia.* Diretta; l'unico punto non banale è che in un anello commutativo un operatore che annulla il generatore annulla tutto il modulo ciclico.
*Prova.* (i) W è stabile per ogni Q(∂) perché Q(∂)(Q′(∂)u) = (QQ′)(∂)u ∈ W. Q ↦ Q(∂)|_W è additiva, moltiplicativa ((QQ′)(∂) = Q(∂)Q′(∂) sulle distribuzioni) e manda 1 nell'identità. Se Q(∂)u = 0, allora per ogni w = Q′(∂)u ∈ W si ha Q(∂)w = Q′(∂)(Q(∂)u) = 0, perché gli operatori a coefficienti costanti commutano: ρ_u(Q) = 0. Viceversa, se ρ_u(Q) = 0, in particolare Q(∂)u = 0 (u = 1(∂)u ∈ W). Dunque ker ρ_u = Ann(u) e, per il primo teorema di omomorfismo, ρ_u(R) ≅ R/Ann(u). Infine Q(∂)|_W = Σ q_α ∂_t^{α₁}∂_x^{α₂}|_W = Σ q_αA_u^{α₁}B_u^{α₂}.
(ii) ker(ρ_u|_𝓛) = 𝓛 ∩ ker ρ_u = 𝓛 ∩ Ann(u) per (i). Rango + nullità = dim 𝓛.
(iii) L ∈ 𝓐 ∩ Ann(u) ⟺ L − L* ∈ 𝓛₀ e (L − L*)(∂)u = 0 (perché L*(∂)u = 0) ⟺ L − L* ∈ 𝓛₀ ∩ Ann(u) = ker(ρ_u|_{𝓛₀}). Per 𝓔_n: τ − b ∈ Ann(u) ⟺ ρ_u(τ − b) = 0 ⟺ A_u = b(B_u).

#### [P4-L1] Semplicità dell'algebra di Weyl — PROVA SCRITTA (fatto classico; prova breve inclusa)

### §C.3. Sintesi spettrale sul modulo ciclico (P4.1, "Z(u)" su un dominio limitato)

#### [P4-T2] Teorema spettrale del modulo ciclico — PROVA SCRITTA

*Tesi.*

Le h_c sono reali-analitiche in t con tutte le derivate nulle in t₀ per (2), quindi h_c ≡ 0 vicino a t₀. Dunque v = 0 vicino a p₀ e, per analiticità, su Ω: a(τ) ∈ Ann(u). Per simmetria (scambiando i ruoli e usando i monomi con j ≤ −1, i ≥ 0) b(ξ) ∈ Ann(u). *Conseguenze.* Se esiste un denominatore separabile, a(τ), b(ξ) ∈ Ann(u) e V(Ann u) ⊆ V(a(τ)) ∩ V(b(ξ)) è finito: u ∈ EP (C3-L3(e)). Viceversa per u EP, Ann(u) ∩ ℂ[τ] ≠ 0 (μ_A(A) = 0 dà μ_A(∂_t)u = 0) e lo stesso per ξ. Le coppie ammissibili sono (Ann(u) ∩ ℂ[τ])∖{0} × (Ann(u) ∩ ℂ[ξ])∖{0}, ideali principali di ℂ[τ], ℂ[ξ] generati da μ_t, μ_x. Infine a(τ) ∈ Ann(u) ⟺ a(A) = 0 su W (P4-T1(i)) ⟺ μ_A | a: μ_t = μ_A, μ_x = μ_B.
(iv) Esempio SymPy C3e–C3i: u = x e^{t+x} + e^{4t+2x}, p₀ = 0: S_u ha denominatore (z₁−1)(z₁−4)(z₂−1)²(z₂−2) = μ_A(z₁)μ_B(z₂); a·b·S_u è polinomio con a = μ_A, b = μ_B, non con b = (z₂−1)(z₂−2); Ann(u) ∩ R_{≤2} calcolato per contrazione (jet di ordine 6) coincide con il calcolo diretto (dimensione 3), mentre Ann(u) non è generato dalle sole eliminanti: (τ−1)(ξ−2) ∈ Ann(u) ((τ−1) annulla x e^{t+x}, (ξ−2) annulla e^{4t+2x}) ma non sta nell'ideale ((τ−1)(τ−4), (ξ−1)²(ξ−2)), la cui varietà ha 4 punti contro i 2 di V(Ann u). ∎
*Casi limite.* d = 1 (u = c e^{⟨z,·⟩}): S_u = c e^{⟨z,p₀⟩}/((z₁−τ_z)(z₂−ξ_z)). u = 0: S_u = 0, ogni coppia ammissibile.
*Rischi.* (iii)"⇒" usa l'analiticità in t di h_c: h_c(t) = ∂_x^cv(t,x₀) è reale-analitica perché v lo è su Ω.

#### [P4-C3] Una serie del jet razionale senza denominatore separabile — PROVA SCRITTA (controesempio a "S_u razionale ⇒ u ∈ EP")
*Dato.* u(t,x) = I₀(2√(tx)) := Σ_{n≥0}(tx)^n/(n!)², funzione intera su ℝ², p₀ = (0,0), Ω ⊂ ℝ² aperto connesso con 0 ∈ Ω.
*Tesi.* (a) s_{ab} = δ_{ab}, quindi S_u = Σ_n (z₁z₂)^{−n−1} = 1/(z₁z₂ − 1), razionale. (b) (∂_t∂_x − 1)u = 0. (c) Ann(u) ∩ ℂ[τ] = 0: u ∉ EP, nessun denominatore separabile. (d) Ann(u) = (τξ − 1): u **identifica** τξ − 1 (Klein–Gordon in coordinate caratteristiche), e il denominatore di S_u coincide qui con il generatore.
*Prova.* (a) ∂_t^a∂_x^b(tx)^n|_0 = (n!)² se a = b = n, 0 altrimenti; diviso (n!)² dà δ_{ab}. Per |z₁z₂| > 1, Σ_n(z₁z₂)^{−n−1} = 1/(z₁z₂ − 1). (b) ∂_t∂_x(tx)^n/(n!)² = n²(tx)^{n−1}/(n!)² = (tx)^{n−1}/((n−1)!)². (c) Se a(τ) = Σ_ka_kτ^k ∈ Ann(u), allora per ogni i, b ≥ 0: 0 = ∂_t^i∂_x^b(a(∂_t)u)(0) = Σ_ka_ks_{k+i,b} = a_{b−i} (se 0 ≤ b−i ≤ deg a, altrimenti 0); con i = 0 e b = k si ottiene a_k = 0 per ogni k. Per P4-T3(iii) u ∉ EP (o direttamente: un EP ha eliminanti non nulle). (d) τξ − 1 è irriducibile (grado 1 in τ, coefficienti ξ e −1 coprimi) e u ∉ EP: per C3-T1(a) con r = 1, Ann(u) = (τξ − 1). ∎ SymPy C4a–C4d (serie troncate; nessuna eliminante in τ di grado ≤ 6).
*Lettura.* In 2D la razionalità di S_u non è il criterio giusto: i dati "di Goursat" sugli assi (qui u(t,0) = u(0,x) = 1) possono rendere razionale la serie anche per una soluzione identificante. Il criterio giusto per "u ∈ EP" è il denominatore **separabile** (iii). E il denominatore non separabile, quando c'è, non è in generale un generatore di Ann(u): nel caso generale Q∘S_u = 0 significa solo che Q·S_u ha parte "strettamente negativa" nulla, mentre le parti miste codificano i dati sugli assi per p₀.

### §C.5. Identificazione e scomposizione per fattori (raccordo con G★′ punto 2)
#### [P4-L2] Fattore coprimo e parte EP — PROVA SCRITTA
*Ipotesi.* Ω aperto connesso, Q, B ∈ R non nulli senza fattori comuni, v ∈ D′(Ω) con Q(∂)v = 0.
*Tesi.* B(∂)v ∈ EP(Ω) ⟺ v ∈ EP(Ω).
*Prova.* (⇐) EP è stabile per derivazione (C3-L3(a)). (⇒) Sia K := Ann(B(∂)v); V(K) è finito (C3-L3(c)). Ann(v) ⊇ (Q) + B·K, quindi V(Ann v) ⊆ V(Q) ∩ (V(B) ∪ V(K)) ⊆ (V(Q) ∩ V(B)) ∪ V(K). V(Q) ∩ V(B) è finito (Fatto (V) di C3-L2; se Q o B è costante l'intersezione è vuota). Quindi V(Ann v) è finito e v ∈ EP (C3-L3(e)). ∎

#### [P4-P1] Identificazione per componenti — PROVA SCRITTA
*Ipotesi.* Ω ⊂ ℝ² aperto connesso e semplicemente connesso (H¹_dR(Ω) = 0); P = c∏_{j=1}^rP_j^{m_j} (P_j irriducibili a due a due non associati, m_j ≥ 1); u ∈ D′(Ω) con P(∂)u = 0; u = Σ_ju_j con u_j ∈ ker_{D′(Ω)}P_j^{m_j} (una scomposizione qualsiasi: esiste per C12-T1′, DIMOSTRATO).
*Tesi.* (a) Ann(u) = (P) ⟺ per ogni j, Ann(u_j) = (P_j^{m_j}) ⟺ per ogni j, P_j^{m_j−1}(∂)u_j ∉ EP(Ω). (b) V(Ann u) = V(P) ⟺ per ogni j, u_j ∉ EP(Ω). (c) Le condizioni non dipendono dalla scomposizione scelta.
*Prova.* Sia B_j := P/P_j^{m_j} (a meno della costante c), coprimo con P_j. (a) Per C3-T1(a), Ann(u) = (P) ⟺ w_j := (P/P_j)(∂)u ∉ EP per ogni j. Per k ≠ j, P_k^{m_k} divide P/P_j, quindi (P/P_j)(∂)u_k = 0, e w_j = (P/P_j)(∂)u_j = c·B_j(∂)v_j con v_j := P_j^{m_j−1}(∂)u_j, che soddisfa P_j(∂)v_j = 0. Per P4-L2 (Q = P_j, B = B_j), w_j ∈ EP ⟺ v_j ∈ EP. Infine C3-T1(a) applicato a u_j e all'operatore P_j^{m_j} (un solo fattore irriducibile, con molteplicità m_j) dà Ann(u_j) = (P_j^{m_j}) ⟺ (P_j^{m_j}/P_j)(∂)u_j = v_j ∉ EP. (b) Per C3-T1(b), V(Ann u) = V(P) ⟺ w_j′ := (P/P_j^{m_j})(∂)u ∉ EP per ogni j; come sopra w_j′ = c·B_j(∂)u_j, e P4-L2 con Q = P_j^{m_j} dà w_j′ ∈ EP ⟺ u_j ∈ EP. (c) Le condizioni equivalgono a condizioni su u (w_j, w_j′), che non dipendono dalla scomposizione. ∎ SymPy C5a–C5b (calore × trasporto, u = G + e^{x−t}: la componente di trasporto è EP, quindi u non identifica; w per il fattore del calore non è EP).
*Lettura.* L'identificazione si legge **componente per componente**: u identifica P se e solo se ogni componente u_j identifica il proprio fattore primario. L'ambiguità della scomposizione (EP, dimensione δ(P), C12-T1′) non tocca il criterio, perché aggiungere un EP a una componente identificante non la rende EP (P4-L2 / C3-T1). La semplice connessione serve solo all'esistenza della scomposizione; su Ω non semplicemente connesso il criterio C3-T1 si applica comunque a u.

### §C.6. Decidibilità (C3-Q1): riduzione, impossibilità a scatola nera, classe decidibile
*Domanda (C3-Q1).* Il criterio C3-T1 ("w_i ∉ EP") è una caratterizzazione, non una procedura. Per quali modelli di dato "Ann(u) = (P)" è decidibile e Ann(u) calcolabile?
**Modello a oracoli M2⁺.** Ω aperto connesso, u reale-analitica su Ω, p₀ ∈ Ω. Oracolo (J): dato α ∈ ℕ², restituisce ∂^αu(p₀) ∈ K (K = ℚ̄). Oracolo (Z): dato Q ∈ K[τ,ξ], dice se Q(∂)u = 0 su Ω. Un algoritmo è una procedura deterministica che esegue aritmetica esatta in K (assunzione (AC)) e un numero finito di interrogazioni, eventualmente scelte in base alle risposte precedenti. P ∈ K[τ,ξ] non costante, con P(∂)u = 0, è dato insieme alla sua fattorizzazione in irriducibili su ℂ, con fattori in K[τ,ξ].

#### [P4-T4] Riduzione di C3-Q1 a un maggiorante della parte EP — PROVA SCRITTA
*Tesi.* Nel modello M2⁺:
(i) per ogni sottospazio 𝓛 ⊆ R di dimensione finita con una base in K[τ,ξ], Ann(u) ∩ 𝓛 ha una base in K[τ,ξ] ed è **calcolabile**;
(ii) "Ann(u) ≠ (P)" è **semi-decidibile** (esiste un algoritmo che termina con "sì" ⟺ Ann(u) ≠ (P));
(iii) se è dato anche un intero B ≥ dim_ℂ(W ∩ EP(Ω)), allora "Ann(u) = (P)" è **decidibile**: Ann(u) = (P) ⟺ Ann(u) ∩ R_{≤N} = (P) ∩ R_{≤N} con N := B + deg P − 1; inoltre il test "Q(∂)u ∈ EP?" è decidibile per ogni Q ∈ K[τ,ξ], quindi G_u (C3-T6) e V(Ann u) = V(P)? (C3-T1(b)) sono calcolabili.
*Prova.* (i) Per k ≥ 0 sia A_k := {Q ∈ 𝓛 : ∂^β(Q(∂)u)(p₀) = 0 ∀|β| ≤ k}: è il nucleo di una matrice a entrate ∂^{β+α}u(p₀) ∈ K (oracolo J), quindi ha una base in K calcolabile per eliminazione di Gauss. A_0 ⊇ A_1 ⊇ … ⊇ Ann(u) ∩ 𝓛. La catena di sottospazi di 𝓛 (dimensione finita) si stabilizza: A_k = A_∞ := ∩_kA_k per k ≥ k*. Se Q ∈ A_∞, Q(∂)u è analitica con serie di Taylor nulla in p₀, quindi nulla su Ω connesso: A_∞ = Ann(u) ∩ 𝓛 (è C3-P2, la cui prova è questa). In particolare Ann(u) ∩ 𝓛 = A_{k*} ha una base in K. *Algoritmo:* per k = 0, 1, 2, …: si calcola una base Q_1, …, Q_s di A_k in K[τ,ξ] e si interroga (Z) su ciascun Q_l; se tutte le risposte sono "nullo", A_k ⊆ Ann(u) ∩ 𝓛 ⊆ A_k e si restituisce A_k. Termina al più per k = k*, dove tutte le risposte sono "nullo"; è corretto perché si ferma solo quando A_k ⊆ Ann(u).
(ii) Per n = deg P, deg P + 1, …: si calcola Ann(u) ∩ R_{≤n} con (i) e lo si confronta per dimensione con (P) ∩ R_{≤n} = P·R_{≤n−deg P} (che vi è contenuto); se la dimensione è maggiore si termina con "sì". Se Ann(u) ≠ (P), esiste Q ∈ Ann(u)∖(P) e il ciclo termina per n = max(deg Q, deg P). Se Ann(u) = (P), non termina.
(iii) *(Grado dei testimoni.)* Supponiamo Ann(u) ≠ (P). Per C3-T1(a) esiste i con w_i := (P/P_i)(∂)u ∈ EP; w_i ∈ W ∩ EP e R·w_i ⊆ W ∩ EP (P4-T2(iii) o C3-L3(a)), quindi d_i := dim R·w_i ≤ B. Se w_i = 0 poniamo h := 1. Altrimenti Ann(w_i) è generato da elementi di grado ≤ d_i (C3-T3(ii), DIMOSTRATO) e non tutti i generatori sono divisibili per P_i, altrimenti Ann(w_i) ⊆ (P_i) contro il Fatto (F) (V(Ann w_i) è finito, V(P_i) no); sia h un generatore con P_i ∤ h, deg h ≤ d_i ≤ B. Allora Q := h·P/P_i ∈ Ann(u)∖(P) (come in C3-T1(a,⇒)) e deg Q ≤ B + deg P − deg P_i ≤ N. Quindi Ann(u) ≠ (P) ⟹ Ann(u) ∩ R_{≤N} ⊋ (P) ∩ R_{≤N}; il viceversa è ovvio. Il confronto è calcolabile per (i). *(Test EP.)* Sia w := Q(∂)u. Gli oracoli per w si ottengono da quelli di u (jet: ∂^αw(p₀) = Σq_γ∂^{α+γ}u(p₀); zero: Q′(∂)w = 0 ⟺ (Q′Q)(∂)u = 0). Se w ∈ EP, allora w ∈ W ∩ EP, d_w := dim R·w ≤ B e i polinomi minimi di ∂_t, ∂_x su R·w hanno grado ≤ B: Ann(w) ∩ ℂ[τ]_{≤B} ≠ 0 e Ann(w) ∩ ℂ[ξ]_{≤B} ≠ 0. Viceversa, se esistono annullatori non nulli a(τ), b(ξ), V(Ann w) è finito e w ∈ EP (C3-L3(e)). Le due intersezioni si calcolano con (i). Con l'oracolo "∈ EP?" così ottenuto, C3-T6 dà G_u (al più Σe_i test) e C3-T1(b) decide V(Ann u) = V(P). ∎
*Lettura.* Con un test di zero, C3-Q1 si riduce **esattamente** a una domanda di finitezza effettiva: conoscere un maggiorante di dim(R·u ∩ EP) = dim R/J_u (P4-T2(iii)). Il teorema seguente mostra che il maggiorante non si può eliminare.

#### [P4-T5] Impossibilità nel modello a scatola nera — PROVA SCRITTA
*Ipotesi.* P ∈ K[τ,ξ] non costante, P = c∏P_i^{e_i} con P_i ∈ K[τ,ξ]; Ω aperto connesso; p₀ ∈ Ω con coordinate in K ∩ ℝ; u reale-analitica su Ω con P(∂)u = 0, ∂^αu(p₀) ∈ K per ogni α, e **Ann(u) = (P)**. E_P^K := insieme delle combinazioni lineari finite a coefficienti in K delle funzioni g_{i,z,j} del Passo 2 (z ∈ V(P_i) ∩ K²); E_P^K ⊂ ker P ∩ EP(Ω).
*Tesi.* Per ogni K ∈ ℕ e ogni insieme finito 𝒬 ⊂ K[τ,ξ] esiste v ∈ E_P^K (quindi analitica, P(∂)v = 0, jet in K, Ann(v) ⊋ (P)) con ∂^αv(p₀) = ∂^αu(p₀) per |α| ≤ K e, per ogni Q ∈ 𝒬, Q(∂)v = 0 ⟺ Q(∂)u = 0. Di conseguenza **nessun algoritmo del modello M2⁺ decide correttamente "Ann(·) = (P)" su tutto {u} ∪ E_P^K**: la sua esecuzione su u, che termina dopo un numero finito di interrogazioni, si ripete identica su un v che non identifica.
*Prova.* *Passo 1 (punti testimoni).* Per ogni i, V(P_i) contiene infiniti punti con coordinate in K: se deg_τP_i ≥ 1, per ξ₀ ∈ K fuori dagli zeri del coefficiente direttore in τ, P_i(·,ξ₀) ha una radice in K (K algebricamente chiuso); se deg_τP_i = 0, P_i ∼ ξ − ξ₀ con ξ₀ ∈ K e V(P_i) ⊇ K × {ξ₀}. Per z ∈ V(P_i) con ∇P_i(z) ≠ 0 sia η_z ∈ {e₁, e₂} con ∇P_i(z)·η_z ≠ 0, s_z(y) := ⟨η_z, y − p₀⟩ (cioè t − t₀ oppure x − x₀) e e_{i,z} := s_z^{e_i−1}e^{⟨z,y−p₀⟩}. Come nella prova di C3-P1[M2] (passo 2), P(z+∂)s_z^{e_i−1} = 0, quindi e_{i,z} ∈ ker P; i suoi jet in p₀ stanno in K.
*Passo 2 (stesso jet).* Per z come sopra e 0 ≤ j ≤ e_i − 1 sia g_{i,z,j} := s_z^je^{⟨z,y−p₀⟩}. Anche g_{i,z,j} ∈ ker P: sui polinomi in s_z, P_i(z+∂) abbassa il grado esattamente di 1 (P_i(z) = 0, coefficiente direttore moltiplicato per ∇P_i(z)·η_z ≠ 0), quindi P_i^{e_i}(z+∂) annulla i polinomi di grado < e_i, e si conclude con C3-L3(a). Sia J_K(w) := (∂^αw(p₀))_{|α|≤K} e V_K ⊆ K^{R_{≤K}} lo spazio generato dai J_K(g_{i,z,j}) (i qualsiasi, z ∈ V(P_i) ∩ K² con ∇P_i(z) ≠ 0, j < e_i). Con l'accoppiamento ⟨Q, J_Kw⟩ := (Q(∂)w)(p₀) (Q ∈ R_{≤K}) mostriamo V_K^⊥ = (P) ∩ R_{≤K}. "⊇": ⟨PA, J_Kg⟩ = (A(∂)P(∂)g)(p₀) = 0. "⊆": sia Q ∈ R_{≤K} ortogonale a V_K e, per assurdo, P ∤ Q. Il passo 2 della prova di C3-P1[M2] dà i e z ∈ V(P_i), con ∇P_i(z) ≠ 0 e Q′(z) ≠ 0 (Q = P_i^fQ′, f < e_i), tali che Q(∂)g_{i,z,e_i−1} ≠ 0; poiché le condizioni escludono solo insiemi finiti, si può prendere z ∈ K² (Passo 1). Per ogni β, ∂^βg_{i,z,e_i−1} = [(z+∂)^βs_z^{e_i−1}]e^{⟨z,·−p₀⟩} è combinazione K-lineare delle g_{i,z,j}, j < e_i (la derivata nella variabile di s_z abbassa il grado, l'altra annulla il polinomio). Quindi ∂^β(Q(∂)g_{i,z,e_i−1})(p₀) = ⟨Q, J_K(∂^βg_{i,z,e_i−1})⟩ = 0 per ogni β; Q(∂)g_{i,z,e_i−1} ∈ EP ha serie di Taylor nulla in p₀, quindi è nullo: contraddizione. Dunque V_K = ((P) ∩ R_{≤K})^⊥ (dimensione finita) e J_K(u) ∈ V_K, perché ⟨PA, J_Ku⟩ = (A(∂)P(∂)u)(p₀) = 0. J_K(u) e i generatori di V_K hanno coordinate in K, quindi J_K(u) è combinazione K-lineare finita dei generatori (un sistema lineare a coefficienti in K risolubile su ℂ è risolubile su K): esiste v₁ ∈ E_P^K con J_K(v₁) = J_K(u).
*Passo 3 (risposte di zero).* Per Q ∈ (P), Q(∂)u = Q(∂)v = 0 per ogni v ∈ ker P. Sia Q ∈ 𝒬∖(P) (allora Q(∂)u ≠ 0 perché Ann(u) = (P)). Scegliamo i con f := v_{P_i}(Q) < e_i, Q = P_i^fQ′ con P_i ∤ Q′, e un insieme F_Q ⊂ V(P_i) ∩ K² di M > dim R_{≤K} punti distinti con ∇P_i(z) ≠ 0 e Q′(z) ≠ 0 (si evitano insiemi finiti: Fatto (V)). Per z ∈ F_Q, Q(∂)e_{i,z} = [Q(z+∂)s_z^{e_i−1}]e^{⟨z,·−p₀⟩} con Q(z+∂)s_z^{e_i−1} ≠ 0 (grado e_i − 1 − f ≥ 0, come in C3-P1[M2]). La mappa ℂ^{F_Q} → K^{R_{≤K}}, c ↦ J_K(Σc_ze_{i,z}) ha nucleo non nullo (M > dim), con una base in K; sia c ≠ 0 nel nucleo e e_Q := Σc_ze_{i,z}. Allora J_K(e_Q) = 0 e Q(∂)e_Q = Σ_zc_z[Q(z+∂)s_z^{e_i−1}]e^{⟨z,·−p₀⟩} ≠ 0 per C3-L3(b) (esponenti distinti, almeno un coefficiente polinomiale non nullo).
*Passo 4 (scelta generica).* Per λ ∈ K^{𝒬′}, 𝒬′ := 𝒬∖(P), sia v_λ := v₁ + Σ_{Q∈𝒬′}λ_Qe_Q ∈ E_P^K: J_K(v_λ) = J_K(u). Per ogni Q ∈ 𝒬′, l'insieme H_Q := {λ : Q(∂)v_λ = 0} è un sottospazio affine di K^{𝒬′} (condizione lineare affine in λ) ed è proprio: se Q(∂)v₁ ≠ 0, λ = 0 ∉ H_Q; se Q(∂)v₁ = 0, il vettore con λ_Q = 1 e gli altri nulli non sta in H_Q (Q(∂)e_Q ≠ 0). Un'unione finita di sottospazi affini propri non ricopre K^{𝒬′} (K infinito): esiste λ con Q(∂)v_λ ≠ 0 per ogni Q ∈ 𝒬′. v := v_λ ha lo stesso K-jet di u e le stesse risposte di zero su 𝒬; v ∈ EP ∩ ker P, quindi Ann(v) ⊋ (P) (C3-C2).
*Passo 5 (algoritmi).* Un algoritmo corretto su u termina con "Ann = (P)" dopo aver interrogato jet di ordine ≤ K e zero-test su un insieme finito 𝒬. Su v le risposte coincidono (per induzione sulle interrogazioni: ogni interrogazione dipende solo dalle risposte precedenti, che coincidono), quindi l'esecuzione è identica e l'uscita "Ann = (P)" è sbagliata per v. ∎ SymPy C8 (calore, u = G in (1,0), K = 2, 𝒬 = {ξ, τ+1}: v EP con 9 modi e^{k²(t−1)+kx}).
*Nota sulla prova.* Il Passo 2 riprende C3-P1[M2] (DIMOSTRATO) con due precisazioni: punti con coordinate in K, e generatori g_{i,z,j} con tutti i j < e_i (servono perché lo span dei jet sia chiuso per derivazione).
*Portata.* L'impossibilità riguarda il modello a scatola nera (jet + test di zero), non una classe concreta di u descritte da formule: per classi con struttura in più (P4-T6) il problema è decidibile. Non affermiamo l'indecidibilità per u olonome qualsiasi.

### Lemmi per una classe decidibile (una variabile)
Notazione: per L ∈ ℂ[x]⟨∂⟩ (∂ = d/dx) scriviamo L = Σ_{i=0}^{D}x^iM_i(∂) con M_i ∈ ℂ[ξ] e M_D ≠ 0 (D = grado in x). Per λ ∈ ℂ, L_λ := Σ_ix^iM_i(∂+λ) = Σ_{i,j}m_{ij}(λ)x^i∂^j; si ha L(q e^{λx}) = e^{λx}L_λq perché ∂(e^{λx}h) = e^{λx}(∂+λ)h. n^{\underline j} := n(n−1)⋯(n−j+1) (fattoriale decrescente).

#### [P4-L3] Soluzioni EP di un'ODE a coefficienti polinomiali: maggiorante calcolabile — PROVA SCRITTA
*Ipotesi.* L ∈ ℂ[x]⟨∂⟩∖{0}, J₀ ⊂ ℝ intervallo aperto, g = Σ_{k=1}^Kq_k(x)e^{λ_kx} (λ_k distinti, q_k ≠ 0) con Lg = 0 su J₀.
*Tesi.* Per ogni k: (a) M_D(λ_k) = 0; (b) ι_{λ_k}(deg q_k) = 0, dove per λ ∈ ℂ, δ_λ := max{i − j : m_{ij}(λ) ≠ 0} e ι_λ(n) := Σ_{i−j=δ_λ} m_{ij}(λ)n^{\underline j}, polinomio **non nullo** in n. Quindi dim ℂ[∂]g ≤ Σ_k(deg q_k + 1) ≤ **B(L) := Σ_{λ: M_D(λ)=0}(N_λ + 1)**, con N_λ := max{n ∈ ℕ : ι_λ(n) = 0} (N_λ := −1 se non esiste; B(L) := 0 se M_D è costante). Se L ∈ K[x]⟨∂⟩, B(L) è calcolabile (assunzione AC).
*Prova.* Lg = Σ_ke^{λ_kx}L_{λ_k}q_k con L_{λ_k}q_k polinomi; per C3-L3(b) in una variabile ogni L_{λ_k}q_k = 0. Sia q un polinomio di grado n ≥ 0 con coefficiente direttore q_n ≠ 0 e L_λq = 0. (a) Il termine x^D M_D(∂+λ)q = x^D(M_D(λ)q + polinomio di grado < n) contiene x^{D+n} con coefficiente M_D(λ)q_n; i termini con i < D hanno grado ≤ i + n < D + n. Quindi M_D(λ) = 0. (b) L_λ ≠ 0 (è e^{−λx}∘L∘e^{λx}), quindi δ_λ è definito. L_λx^n = Σ_{i,j}m_{ij}n^{\underline j}x^{n+i−j}: il monomio x^{n+δ_λ} ha coefficiente ι_λ(n)q_n; i monomi x^{n′} di q con n′ < n producono gradi ≤ n′ + δ_λ < n + δ_λ. Quindi ι_λ(n) = 0. ι_λ ≢ 0: è una combinazione con coefficienti non tutti nulli di fattoriali decrescenti n^{\underline j} con j distinti (a i − j = δ_λ fissato, j distinti ⟺ (i,j) distinti), che hanno gradi distinti e sono linearmente indipendenti. *Conteggio.* ℂ[∂]g ⊆ ⊕_kℂ[x]_{≤deg q_k}e^{λ_kx} (C3-L3(a) in una variabile), dimensione Σ_k(deg q_k + 1); i λ_k sono radici distinte di M_D e deg q_k ≤ N_{λ_k}. *Calcolabilità.* Le radici di M_D ∈ K[ξ] sono in K; ι_λ ∈ K[n]; le sue radici intere non negative si trovano fra le radici in K (test di uguaglianza in K, AC). ∎ SymPy C6a (x∂ − 5: B = 6, soluzione x⁵), C6b (∂ + 2x: B = 0), C6c ((∂−2)²(∂−1): B = 3), C6d (fetta del calore 2∂ + x: B = 0).

#### [P4-L4] Test di zero in un punto tramite il polinomio indiciale — PROVA SCRITTA
*Ipotesi.* L′ = Σ_jb_j(x)∂^j ∈ ℂ[x]⟨∂⟩∖{0}, x₀ ∈ ℂ, b_j(x) = Σ_iβ_{ij}(x−x₀)^i; δ := min{i − j : β_{ij} ≠ 0}, ι_{x₀}(n) := Σ_{i−j=δ}β_{ij}n^{\underline j} (≢ 0 come in P4-L3), K₀ := max{n ∈ ℕ : ι_{x₀}(n) = 0} (−1 se non esiste). h analitica in un intorno di x₀, L′h = 0 vicino a x₀.
*Tesi.* Se h^{(k)}(x₀) = 0 per ogni 0 ≤ k ≤ K₀, allora h ≡ 0 vicino a x₀.
*Prova.* Se h ≢ 0, sia n₀ l'ordine di annullamento in x₀ e h = Σ_{n≥n₀}h_n(x−x₀)^n con h_{n₀} ≠ 0. L′(x−x₀)^n = Σβ_{ij}n^{\underline j}(x−x₀)^{n+i−j}; nella serie convergente L′h il monomio di grado minimo possibile è (x−x₀)^{n₀+δ}, con coefficiente ι_{x₀}(n₀)h_{n₀} (gli h_n con n > n₀ danno gradi ≥ n + δ > n₀ + δ). Da L′h = 0 segue ι_{x₀}(n₀) = 0, quindi n₀ ≤ K₀; ma h^{(k)}(x₀) = 0 per k ≤ K₀ dà n₀ > K₀. Contraddizione. ∎ SymPy C6e. (Vale anche se x₀ è un punto singolare di L′.)

#### [P4-L5] Annullatore di una combinazione di funzioni D-finite — PROVA SCRITTA
*Ipotesi.* J₀ intervallo aperto; f_1,…,f_s analitiche su J₀ con L_lf_l = 0, L_l = Σ_{k≤r_l}a_{l,k}(x)∂^k ∈ K[x]⟨∂⟩, a_{l,r_l} ≠ 0; c_1,…,c_s ∈ K[ξ]; g := Σ_lc_l(∂)f_l.
*Tesi.* Si calcola L_g ∈ K[x]⟨∂⟩∖{0} con L_gg = 0 su J₀; se si conoscono i jet delle f_l in x₀ ∈ J₀, si conoscono quelli di g.
*Prova.* Se r_l = 0, a_{l,0}f_l = 0 dà f_l = 0 fuori da un insieme finito, quindi f_l ≡ 0: si scarta. Sia N = Σr_l e V = K(x)^N con base simbolica e_{l,k} (k < r_l). Sia 𝒟 : V → V additiva, 𝒟(φe_{l,k}) = φ′e_{l,k} + φe_{l,k+1}, con la convenzione e_{l,r_l} := −Σ_{k<r_l}(a_{l,k}/a_{l,r_l})e_{l,k}. Sia Σ ⊂ J₀ l'insieme finito degli zeri reali dei denominatori in gioco e ε(Σφ_{l,k}e_{l,k}) := Σφ_{l,k}f_l^{(k)} su J₀∖Σ. Poiché f_l^{(r_l)} = −Σ_k(a_{l,k}/a_{l,r_l})f_l^{(k)} su J₀∖Σ, vale ε(𝒟v) = (εv)′. Sia γ := Σ_lc_l(𝒟)e_{l,0}, così ε(γ) = g. I vettori γ, 𝒟γ, …, 𝒟^Nγ sono N+1 vettori di uno spazio di dimensione N su K(x): l'eliminazione di Gauss su K(x) dà φ_0,…,φ_N non tutti nulli con Σφ_j𝒟^jγ = 0; moltiplicando per un denominatore comune, b_j ∈ K[x] non tutti nulli. Allora Σ_jb_jg^{(j)} = ε(Σb_j𝒟^jγ) = 0 su J₀∖Σ e, per continuità, su J₀. L_g := Σb_j∂^j ≠ 0. Jet: g^{(k)}(x₀) = Σ_l(∂^kc_l(∂)f_l)(x₀). (Se N = 0, g = 0 e L_g = 1.) ∎ SymPy C6g (f = e^{−x²/4} + e^{1+x}: L_f = (2x+4)∂² + (x²−6)∂ − (x²+2x−2)).

#### [P4-P2] Test "∈ EP" in una variabile — PROVA SCRITTA
*Ipotesi.* g analitica su J₀, x₀ ∈ J₀ ∩ K; dato L_g ∈ K[x]⟨∂⟩∖{0} con L_gg = 0 su J₀; per ogni k si sa calcolare g^{(k)}(x₀) ∈ K.
*Tesi.* "g ∈ EP(J₀)" è decidibile.
*Algoritmo e prova.* Sia B := B(L_g) (P4-L3). *Caso B = 0:* g ∈ EP ⟺ g = 0 (un EP non nullo che risolve L_g darebbe B ≥ 1 per P4-L3); si decide g = 0 con P4-L4 (jet fino a K₀(L_g, x₀); g = 0 vicino a x₀ ⟺ g = 0 su J₀ per analiticità). *Caso B ≥ 1:* sia H := (g^{(i+j)}(x₀))_{0≤i≤B−1, 0≤j≤B} ∈ K^{B×(B+1)} e N_H ⊆ K^{B+1} il suo nucleo, identificato con polinomi di ℂ[ξ]_{≤B}. Se g ∈ EP, allora d := dim ℂ[∂]g ≤ B (P4-L3) e, per C3-T3(i) applicato a G(t,x) := g(x) su (−1,1)×J₀ (connesso; R·G = ℂ[∂_x]g, Q ∈ ℂ[ξ]_{≤B}, maggiorante d′ = B ≥ d, nota T3-2: le condizioni con derivate in t sono automatiche), N_H = Ann(g) ∩ ℂ[ξ]_{≤B}. Si procede così: se N_H = 0, si risponde "non EP" (se g fosse EP, 0 ≠ p_g ∈ N_H, oppure g = 0 e N_H = tutto); altrimenti si prende p ∈ N_H∖{0} a coefficienti in K e si decide se p(∂)g = 0 (annullatore di p(∂)g con P4-L5, poi P4-L4). Se p(∂)g = 0, g ∈ EP (in una variabile, p ≠ 0 annulla g); se p(∂)g ≠ 0, g ∉ EP (se g fosse EP, ogni elemento di N_H lo annullerebbe). ∎ SymPy C6f (Hankel 3×4 per x e^{2x} + eˣ: nucleo (ξ−2)²(ξ−1)), C6i, C6j.

#### [P4-L6] Dati di Cauchy di una soluzione analitica — PROVA SCRITTA
*Ipotesi.* P ∈ R monico in τ di grado m ≥ 1, P = τ^m + Σ_{j<m}p_j(ξ)τ^j; Ω aperto connesso; t₀ ∈ ℝ e J₀ intervallo aperto con {t₀}×J₀ ⊂ Ω; v reale-analitica su Ω con P(∂)v = 0; Cauchy(v) := (∂_t^jv(t₀,·)|_{J₀})_{j<m}.
*Tesi.* (a) Cauchy(v) = 0 ⟹ v ≡ 0 su Ω. (b) v ∈ EP(Ω) ⟺ ogni componente di Cauchy(v) sta in EP(J₀). (c) Per Q ∈ R, scritto τ^lQ ≡ Σ_{j<m}c^Q_{lj}(ξ)τ^j (mod P) (divisione per il monico P in ℂ[ξ][τ]), si ha ∂_t^l(Q(∂)v)(t₀,x) = Σ_jc^Q_{lj}(∂_x)[∂_t^jv(t₀,·)](x) per x ∈ J₀.
*Prova.* (c) τ^lQ = A·P + Σ_jc^Q_{lj}τ^j e A(∂)P(∂)v = 0; la restrizione a t = t₀ commuta con ∂_x. (a) Sia x₁ ∈ J₀. Per j < m, ∂_x^b∂_t^jv(t₀,x₁) = ∂_x^b[∂_t^jv(t₀,·)](x₁) = 0. Per j ≥ m, ∂_t^jv = −Σ_{l<m}p_l(∂_x)∂_t^{j−m+l}v, e per induzione su j tutte le derivate ∂_x^b∂_t^jv(t₀,x₁) sono nulle. v è analitica con serie di Taylor nulla in (t₀,x₁): v = 0 vicino a quel punto e, per analiticità e connessione, su Ω. (b) (⇒) Le derivate in t e le restrizioni a una retta di un EP sono EP in una variabile. (⇐) Sia F = (f_0,…,f_{m−1}) = Cauchy(v), con f_j = restrizione di un EP di una variabile; raccogliendo gli esponenziali, F = Σ_ke^{ξ_kx}Q_k(x) con ξ_k distinti e Q_k ∈ ℂ[x]^m, deg ≤ δ. Sia C(ξ) la compagna di P (II §1). Per C3-L3(a), C(∂_x)(e^{ξ_kx}Q) = e^{ξ_kx}C(ξ_k+∂_x)Q, e M_k := C(ξ_k+∂_x) è un operatore lineare dello spazio (ℂ[x]_{≤δ})^m, di dimensione finita. Poniamo U(t,x) := Σ_ke^{ξ_kx}[exp((t−t₀)M_k)Q_k](x): le entrate di exp((t−t₀)M_k) sono EP in t (esponenziale di una matrice), quindi U ∈ EP(ℝ²)^m, ∂_tU = C(∂_x)U e U(t₀,·) = F. Per II-L1(b) (biiezione tra ker P e le soluzioni del sistema del primo ordine, valida in ogni R-modulo, qui C^∞(ℝ²)), E := U_1 risolve P(∂)E = 0 con ∂_t^jE = U_{j+1}, quindi Cauchy(E|_Ω) = F. Allora v − E|_Ω è analitica, risolve P e ha dati di Cauchy nulli: per (a) v = E|_Ω ∈ EP(Ω). ∎ SymPy C7 (onda, dati x eˣ ed e^{2x}).

#### [P4-T6] C3-Q1 è decidibile per soluzioni analitiche con dati di Cauchy D-finiti — PROVA SCRITTA
*Ipotesi.* (H1) P ∈ K[τ,ξ] monico in τ di grado m ≥ 1, con fattorizzazione data P = ∏_iP_i^{e_i} in irriducibili su ℂ, a due a due non associati, P_i ∈ K[τ,ξ] (normalizzabili monici in τ: i loro coefficienti direttori in τ sono polinomi in ξ con prodotto 1, quindi costanti). (H2) Ω ⊂ ℝ² aperto connesso, u reale-analitica su Ω con P(∂)u = 0. (H3) t₀ ∈ ℝ, J₀ intervallo aperto, {t₀}×J₀ ⊂ Ω, x₀ ∈ J₀ ∩ K. (H4) per ogni j < m sono dati L_j ∈ K[x]⟨∂⟩∖{0} con L_jf_j = 0 su J₀, dove f_j := ∂_t^ju(t₀,·)|_{J₀}, il coefficiente direttore di L_j non nullo in x₀, e i valori f_j^{(k)}(x₀) ∈ K per k < ord L_j. (AC).
*Tesi.* Sono decidibili "Ann(u) = (P)" e "V(Ann u) = V(P)"; sono calcolabili G_u (C3-T6), Ann(u) ∩ 𝓛 per ogni 𝓛 di dimensione finita definita su K, e un sistema finito di generatori di Ann(u).
*Prova.* *Passo 0 (jet).* f_j^{(k)}(x₀) ∈ K per ogni k: derivando k volte L_jf_j = 0 in x₀, f_j^{(r_j+k)}(x₀) compare con coefficiente a_{j,r_j}(x₀) ≠ 0 e gli altri termini contengono derivate di ordine minore (ricorrenza in K). Le derivate miste di u in p₀ = (t₀,x₀) seguono da P4-L6(c) con Q = 1: ∂_x^b∂_t^au(p₀) = Σ_j(∂_x^bc^1_{aj}(∂_x)f_j)(x₀). *Passo 1 (test di zero).* Per Q ∈ K[τ,ξ], v := Q(∂)u è analitica e P(∂)v = 0; per P4-L6(a), v = 0 ⟺ Cauchy(v) = 0, e per P4-L6(c) le componenti di Cauchy(v) sono g_l = Σ_jc^Q_{lj}(∂_x)f_j: annullatori con P4-L5, jet dal Passo 0, test con P4-L4 (analiticità: g_l = 0 vicino a x₀ ⟺ g_l = 0 su J₀). *Passo 2 (test EP).* Per Q ∈ K[τ,ξ], w := Q(∂)u è analitica e risolve P: per P4-L6(b) w ∈ EP(Ω) ⟺ ogni componente di Cauchy(w) è EP(J₀), e ciascuna si decide con P4-P2 (annullatori da P4-L5). *Conclusione.* C3-T1(a),(b): Ann(u) = (P) ⟺ nessun w_i = (P/P_i)(∂)u è EP; V(Ann u) = V(P) ⟺ nessun w_i′ = (P/P_i^{e_i})(∂)u è EP: decidibili per il Passo 2. G_u: C3-T6 con i test del Passo 2. Ann(u) ∩ 𝓛: P4-T4(i), con gli oracoli dei Passi 0 e 1. *Generatori.* Ann(u) = G_u·J_u con J_u = Ann(w₀), w₀ := G_u(∂)u ∈ EP (P4-T2(iii)). Maggiorante di d₀ := dim R·w₀: la mappa R·w₀ → (funzioni su J₀)^m, v ↦ Cauchy(v), è iniettiva (P4-L6(a)); per P4-L6(c) l'immagine sta in (Σ_jℂ[∂_x]h_j)^m con h_j le componenti di Cauchy(w₀), EP con annullatori L_{h_j} calcolabili (P4-L5); per P4-L3, dim ℂ[∂_x]h_j ≤ B(L_{h_j}), quindi d₀ ≤ B₀ := m·Σ_jB(L_{h_j}). Per C3-T3(ii) Ann(w₀) è generato in grado ≤ d₀ ≤ B₀, e Ann(w₀) ∩ R_{≤B₀} si calcola con P4-T4(i) (oracoli per w₀ come nei Passi 0–1). Generatori di Ann(u): G_u per i generatori di Ann(w₀) ∩ R_{≤B₀}. ∎ SymPy C6g–C6j (calore: u = G + e^{t+x}, fetta t₀ = 1: "non EP", quindi Ann(u) = (τ−ξ²); fetta EP riconosciuta), C6d (fetta del nucleo del calore: B = 0, G identifica senza calcoli ulteriori).
*Complessità.* Non stimata (aritmetica in ℚ̄; i maggioranti B(L) dipendono dalle radici intere dei polinomi indiciali e possono essere grandi rispetto ai dati).

#### [P4-C4] Le ipotesi di P4-T6 non si possono togliere (per il metodo) — PROVA SCRITTA
(a) **Analiticità (H2).** P = τ + ξ (monico), Ω = (0,1)×(−5,5), u = F(x − t) con F = e^s + φ(s), φ ∈ C_c^∞(2,3), φ ≢ 0 (C3-P5(a)). Su Ω u ∉ EP, quindi Ann(u) = (τ+ξ) (C3-T4(a)). Con t₀ = 1/2, J₀ = (−1,1): x − t₀ ∈ (−3/2, 1/2), dove φ = 0, quindi f_0 = e^{x−1/2} è D-finito (∂ − 1) ed EP. Il test di P4-T6 risponderebbe "u ∈ EP, non identifica": P4-L6(b) fallisce senza analiticità, e nessun dato su una fetta decide.
(b) **Monicità in τ (H1).** P = ξ(τ − 1) (coefficiente direttore in τ uguale a ξ), u = e^{t²} (analitica, ∂_xu = 0, quindi P(∂)u = 0). La fetta t = t₀ dà f_0 costante, EP, ma u ∉ EP(Ω): P4-L6(b) fallisce. Qui G_u = ξ (Ann(u) = (ξ), perché e^{t²} non ha annullatori in ℂ[τ]), mentre la procedura di P4-T6 applicata alla fetta direbbe che (P/ξ)(∂)u = (∂_t − 1)u = (2t − 1)e^{t²} è EP (fetta costante) e restituirebbe G_u = 1: sbagliato. (Per P non monico in τ si può prima cambiare coordinate lineari in una direzione non caratteristica, II-T1 osservazione; la fetta va presa trasversale a quella direzione.)
(c) **Struttura D-finita (H4).** Senza un annullatore delle fette manca il maggiorante B, e nel modello a scatola nera il problema non è decidibile (P4-T5). ∎
