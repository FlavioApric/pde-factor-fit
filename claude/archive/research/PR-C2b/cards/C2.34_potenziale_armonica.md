# C2.34 — Flusso potenziale e analisi armonica (T5) · tag ◇ · scheda BREVE

**Operatore** $\Delta$ (2D/3D). **Classe**: armoniche = $\mathrm{Re}$ di potenziali complessi $f(z)$ (coniugate armoniche ↔ Cauchy–Riemann = fattorizzazione $\Delta=4\partial_z\partial_{\bar z}$); formula integrale di Poisson (nucleo del disco verificato, SymPy t4); metodi integrali al bordo (potenziali di strato singolo/doppio); **espansioni multipolari** $r^{-n-1}Y_n$ / $\mathrm{Re}\,z^{-n}$ = base numerabile per il problema esterno.
**Rilevanza**: espansione multipolare = base numerabile duale (interno $r^n$ / esterno $r^{-n-1}$) — modello per il passaggio numerabile↔continuo di A7. Coniugate armoniche = proiezione sulla componente olomorfa (C2.9).
