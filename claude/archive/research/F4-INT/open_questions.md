# open_questions — F4-INT (26/10/2026)
- **INT-Q1 (I, anello intero; = F4-ALG DOMANDA 2).** Una soluzione di KdV con dato di Schwartz e r ≢ 0 può soddisfare, per ogni t, un'ODE autonoma G(u, u_x, …) = 0 (simmetria condizionale generalizzata)? Congettura INT-K1: no, cioè trdeg ℂ⟨u⟩ = ∞; allora INT-T1(b) vale per ogni dizionario. Chiusura: argomento asintotico (radiazione ~ t^{−1/3}Ai) o di Galois differenziale; letteratura GCS (Fokas–Liu 1994, Zhdanov 1995).
