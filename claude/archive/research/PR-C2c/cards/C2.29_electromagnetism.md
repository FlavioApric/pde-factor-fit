# C2.29 — PDE elettromagnetiche (Maxwell, onda EM, elettro/magnetostatica, Helmholtz, potenziali, gauge, BC)
Tag: ◇■ · scheda breve · PR-C2c 2026-10-22

- **Operatore**: `∇×E = −B_t`, `∇×H = J + D_t`, `∇·D = ρ`, `∇·B = 0`. In 1D (onda piana TEM, `E = E_y(x,t)`, `B = B_z(x,t)`): sistema 2×2 `B_t + E_x = 0`, `E_t + c²B_x = 0` ⇒ `E_tt = c²E_xx`; con conducibilità σ: **equazione del telegrafo** `E_tt + (σ/ε)E_t = c²E_xx` (C2.12); in gauge di Lorenz `□A = −μJ`, `□φ = −ρ/ε`; armonico nel tempo: Helmholtz `ΔE + k²E = 0` (C2.35).
- **Classe di soluzioni**: d'Alembert (1D), onde sferiche/multipoli (3D, armoniche sferiche vettoriali, Bessel sferiche), modi di guida d'onda (Bessel in cilindro), telegrafo (Bessel `I_0` nel nucleo).
- **Linearizzazione/separazione**: è lineare; la separazione in componenti è esatta via (i) decomposizione di Helmholtz (longitudinale/trasversale), (ii) polarizzazioni TE/TM, (iii) diagonalizzazione del sistema 1D in onde ± (`E ± cB`, invarianti di Riemann lineari). Nonlinearità solo nei mezzi (Kerr → NLS, C2.45).
- **Interazione**: assente nel vuoto; in mezzi dispersivi/non lineari: mixing a 3/4 onde (C2.64′).
- **Rilevanza G★**: esempio ■ di sistema del 1° ordine la cui componente scalare ricade in ★ (onda, telegrafo); gauge = non unicità del potenziale (analogo della non identificabilità "modulo un sottospazio").
- **Fonti**: Jackson 1999 (*Classical Electrodynamics*, 3ª ed., Wiley); Courant–Hilbert vol. II (1962) cap. VI; Monk 2003 (*Finite Element Methods for Maxwell's Equations*, OUP) per la teoria funzionale (H(curl)).
