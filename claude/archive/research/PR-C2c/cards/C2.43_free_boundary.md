# C2.43 — Problemi a frontiera libera e interfacce mobili (Stefan, fusione/solidificazione, Hele-Shaw, tracciamento di interfacce)
Tag: ▲◇ · scheda breve · PR-C2c 2026-10-22

- **Operatore**: Stefan a una fase: `T_t = T_xx` in `0 < x < s(t)`, `T(s,t) = 0`, condizione di Stefan `s'(t) = −St·T_x(s,t)` (non linearità nascosta nel dominio). Hele-Shaw: `Δp = 0` nel dominio mobile, `V_n = −∂_n p`.
- **Classe di soluzioni**: soluzione di Neumann autosimile `T = A erf(x/2√t)` [M10], fronte `s = 2λ√t` con λ radice di `λe^{λ²}erf(λ) = St/√π`; Hele-Shaw 2D: soluzioni esplicite via mappe conformi polinomiali/razionali (Polubarinova–Galin, Richardson: momenti armonici conservati — integrabile, gerarchia dispersionless Toda).
- **Linearizzazione/separazione**: (i) **trasformazione di Landau / coordinate fisse** `ξ = x/s(t)` porta in dominio fisso a prezzo di coefficienti variabili; (ii) per Stefan 1D: "inversione" (Baiocchi, problema a ostacolo: disequazione variazionale lineare); (iii) Hele-Shaw: mappa conforme + momenti (Richardson) = linearizzazione completa nei momenti. Ogni soluzione nel dominio è nella classe del calore/armonica (★/◇); la non linearità sta solo nella legge dell'interfaccia.
- **Interazione**: accoppiamento campo–interfaccia; instabilità di Mullins–Sekerka / Saffman–Taylor.
- **Rilevanza G★**: identificazione di L dentro il dominio resta lineare (calore); la parte non lineare è una relazione di bordo (C2.54′, S9) — separabile.
- **Fonti**: Crank 1984 (*Free and Moving Boundary Problems*, OUP); Rubinstein 1971 (*The Stefan Problem*, AMS TMM 27); Gustafsson–Vasil'ev 2006 (*Conformal and Potential Analysis in Hele-Shaw Cells*, Birkhäuser); Richardson 1972 (J. Fluid Mech. 56:609).
