# C2.44 — Onde viaggianti e strutture coerenti (riduzione, orbite eterocline/omocline, onde solitarie, impulsi, fronti, treni d'onda, stabilità)
Tag: ▲ · scheda breve · PR-C2c 2026-10-22

- **Operatore**: qualsiasi PDE invariante per traslazioni; ansatz `u = U(z)`, `z = x − ct` riduce `N(∂_t,∂_x,u) = 0` a ODE `N(−c∂_z, ∂_z, U) = 0` (C2.66′, riduzione per simmetria).
- **Classe di soluzioni**: fronti = orbite **eterocline** (Fisher–KPP `U'' + cU' + U(1−U) = 0`; Burgers tanh [B3]); impulsi/solitoni = orbite **omocline** (KdV sech² [K1], NLS sech [M2]); kink sine-Gordon `4 arctan e^{γ(x−vt)}` [M1]; treni d'onda periodici (cnoidali). Fisher–KPP: esistenza per ogni `c ≥ 2` (velocità minima selezionata `c* = 2` da dati compatti); onda esplicita per `c = 5/√6`: `U = (1 + Ce^{z/√6})^{−2}` [M3] (Ablowitz–Zeppetella).
- **Linearizzazione/separazione**: la riduzione stessa è esatta (PDE → ODE); la stabilità usa il **linearizzato** `ℒ = d/dU N|_U` nel frame mobile: spettro essenziale (Fourier sullo stato di fondo) + punti isolati (funzione di Evans `E(λ)`); traslazione dà autovalore 0 con autofunzione `U'`.
- **Interazione**: per fronti dissipativi: interazione debole esponenziale tra fronti/impulsi lontani `~ e^{−μ d}` (dinamica di posizioni, Ei–Elphick ecc.); per integrabili: sfasamenti esatti.
- **Rilevanza G★**: un'onda viaggiante `u(x−ct)` ha annullatore lineare `∂_t + c∂_x` ⇒ **non identificabilità**: un singolo profilo non distingue la PDE non lineare dal trasporto (ogni PDE autonoma ammette lo stesso profilo con ODE diversa). Caso critico per C3/G4 non lineare.
- **Fonti**: Sandstede 2002 (*Stability of travelling waves*, Handbook of Dynamical Systems 2, 983–1055); Kapitula–Promislow 2013 (*Spectral and Dynamical Stability of Nonlinear Waves*, Springer AMS 185); Ablowitz–Zeppetella 1979 (Bull. Math. Biol. 41:835, doi:10.1007/BF02462380); Volpert–Volpert–Volpert 1994 (AMS TMM 140).
