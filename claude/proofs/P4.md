### [P4-L1] Semplicità dell'algebra di Weyl — PROVA SCRITTA (fatto classico; prova breve inclusa)
*Ipotesi.* A_1 = ℂ[x]⟨∂⟩, l'algebra degli operatori su C^∞(I) (I intervallo aperto) generata dalla moltiplicazione per x e da ∂ = d/dx. Ogni elemento si scrive Q = Σ_{i,j} c_{ij}x^i∂^j (forma normale).

*Prova.* (a) Se Q = Σc_{ij}x^i∂^j agisce come 0 su C^∞(I) e qualche c_{ij} ≠ 0, sia j₀ il minimo j con qualche c_{ij} ≠ 0: Q x^{j₀} = Σ_i c_{ij₀} j₀! x^i (i termini con j > j₀ annullano x^{j₀}, quelli con j < j₀ non ci sono) è un polinomio non nullo: assurdo. (b) Sia I ≠ 0 bilatero e Q = Σc_{ij}x^i∂^j ∈ I∖{0}. Valgono [∂, x^i∂^j] = i x^{i−1}∂^j e [x^i∂^j, x] = j x^i∂^{j−1} (Leibniz; SymPy C1c), e [∂,Q], [Q,x] ∈ I perché I è bilatero. Sia j* il massimo j con qualche c_{ij} ≠ 0. Applicando j* volte Q ↦ [Q,x] si ottiene j*!·Σ_i c_{ij*}x^i ∈ I, non nullo. Sia i* il massimo i con c_{ij*} ≠ 0; applicando i* volte ↦ [∂,·] si ottiene la costante i*! j*! c_{i*j*} ≠ 0 in I, quindi 1 ∈ I e I = A_1. (c) [fix L1-1] Forma normale Q = Σ_{α,β}c_{αβ}y^α∂^β (y = (t,x), α, β ∈ ℕ²), unica come in (a) (applicare Q a y^{β₀} con β₀ minimo in ordine lessicografico tra i β presenti). Applicando b₁ volte ad_t := [·, t] e poi b₂ volte ad_x := [·, x]: un monomio con multi-indice β si annulla se β₁ < b₁, oppure β₁ = b₁ e β₂ < b₂; quelli con β₁ > b₁ non esistono per massimalità lessicografica di β*, e se β₁ = b₁ devono avere β₂ ≤ b₂. ## 6. Decidibilità (C3-Q1): riduzione, impossibilità a scatola nera, classe decidibile
*Domanda (C3-Q1).* Il criterio C3-T1 ("w_i ∉ EP") è una caratterizzazione, non una procedura. Per quali modelli di dato "Ann(u) = (P)" è decidibile e Ann(u) calcolabile?
**Modello a oracoli M2⁺.** Ω aperto connesso, u reale-analitica su Ω, p₀ ∈ Ω. Oracolo (J): dato α ∈ ℕ², restituisce ∂^αu(p₀) ∈ K (K = ℚ̄). Oracolo (Z): dato Q ∈ K[τ,ξ], dice se Q(∂)u = 0 su Ω. Un algoritmo è una procedura deterministica che esegue aritmetica esatta in K (assunzione (AC)) e un numero finito di interrogazioni, eventualmente scelte in base alle risposte precedenti. P ∈ K[τ,ξ] non costante, con P(∂)u = 0, è dato insieme alla sua fattorizzazione in irriducibili su ℂ, con fattori in K[τ,ξ].

### [P4-T4] Riduzione di C3-Q1 a un maggiorante della parte EP — PROVA SCRITTA
*Tesi.* Nel modello M2⁺:
(i) per ogni sottospazio 𝓛 ⊆ R di dimensione finita con una base in K[τ,ξ], Ann(u) ∩ 𝓛 ha una base in K[τ,ξ] ed è **calcolabile**;
(ii) "Ann(u) ≠ (P)" è **semi-decidibile** (esiste un algoritmo che termina con "sì" ⟺ Ann(u) ≠ (P));
(iii) se è dato anche un intero B ≥ dim_ℂ(W ∩ EP(Ω)), allora "Ann(u) = (P)" è **decidibile**: Ann(u) = (P) ⟺ Ann(u) ∩ R_{≤N} = (P) ∩ R_{≤N} con N := B + deg P − 1; inoltre il test "Q(∂)u ∈ EP?" è decidibile per ogni Q ∈ K[τ,ξ], quindi G_u (C3-T6) e V(Ann u) = V(P)? (C3-T1(b)) sono calcolabili.
*Prova.* (i) Per k ≥ 0 sia A_k := {Q ∈ 𝓛 : ∂^β(Q(∂)u)(p₀) = 0 ∀|β| ≤ k}: è il nucleo di una matrice a entrate ∂^{β+α}u(p₀) ∈ K (oracolo J), quindi ha una base in K calcolabile per eliminazione di Gauss. A_0 ⊇ A_1 ⊇ … ⊇ Ann(u) ∩ 𝓛. La catena di sottospazi di 𝓛 (dimensione finita) si stabilizza: A_k = A_∞ := ∩_kA_k per k ≥ k*. In particolare Ann(u) ∩ 𝓛 = A_{k*} ha una base in K. *Algoritmo:* per k = 0, 1, 2, …: si calcola una base Q_1, …, Q_s di A_k in K[τ,ξ] e si interroga (Z) su ciascun Q_l; se tutte le risposte sono "nullo", A_k ⊆ Ann(u) ∩ 𝓛 ⊆ A_k e si restituisce A_k. Se Ann(u) ≠ (P), esiste Q ∈ Ann(u)∖(P) e il ciclo termina per n = max(deg Q, deg P). Se Ann(u) = (P), non termina.

Viceversa, se esistono annullatori non nulli a(τ), b(ξ), V(Ann w) è finito e w ∈ EP (C3-L3(e)). Le due intersezioni si calcolano con (i). *Lettura* [fix T5-1, sostituisce la versione precedente, che affermava una riduzione "esatta" e che il maggiorante "non si può eliminare": nessuna delle due cose è dimostrata].
